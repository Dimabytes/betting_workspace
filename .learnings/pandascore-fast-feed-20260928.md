# PandaScore и быстрый фид для Dota: тейкер, лаг и частота обновлений, 2026-09-28

Вопрос 1: покупать ли PandaScore Low Latency Feed (LLF) для Dota и LoL и когда начинать.
Цена: €4 000 = $4 561 в месяц за одну игру, минимального срока нет, проба 2 недели бесплатно.
Вопрос 2: можно ли с фидом быстрее рынка стать тейкером.

## Входные данные и метод

- Два запуска herdr-fleet. Сырые данные, скрипты и отчёты агентов лежат в `.analysis/pandascore-roi-2026-09-27/`
  и `.analysis/taker-zero-lag-2026-09-27/` (в `.gitignore`). Токена там нет: скрипты читают `PANDASCORE_KEY`
  из `esports-trader/.env`.
  - Запуск 1: календари Liquipedia до февраля 2027, объёмы Polymarket (Gamma `volumeNum`), продукт PandaScore, P&L живой ленты.
  - Запуск 2: два агента по тейкеру (Grok 4.7 High, GPT-6 Luna) и ночные бэктесты мейкера.
- Покрытие LLF — по бесплатному токену: `filter[low_latency_feed]=true` работает и на прошлых матчах.
- Живая лента `esports-trader/data/trader/`, 30.08–27.09.2026: 340 карт Dota (258 GRID, 82 Oddin).
- Мейкер: `src/backtest/run.py`, 472 карты validation (04.06–13.09.2026), одни и те же во всех прогонах.
  - Ступень задаёт обёртка `overnight/bt_sized.py` без правки репо (`BT_LEVEL_USDC`, `BUY_LEVEL_COUNT = 3`).
  - `BT_EMPTY_ARCHIVE_INDEX=1` прячет индекс архива. Карты живой ленты (с 30.08, 232 шт.) выпадают:
    на них лаг и каденс менять нельзя (`feed_schedules.reject_schedule_flags`).
  - Модели лага 0: `prepare_dataset --lag-seconds 0 --output-dir`, `train_model --lag-seconds 0` (с XP и `--no-xp`),
    1 564 карты. Модели и прогоны лежат в `esports-trader/data/experiments/zero-lag/` (в `.gitignore`).
- Тейкер: свои симуляции агентов по полному стакану Telonex. Вход через L + 0.5 с после события,
  L ∈ {0, 1.35, 5, 9.65, 15} с. Правило выбрано на первой половине карт по дате, результат — на второй (399 карт).

## Итог

1. **LoL — не покупать.** В LLF LoL нет золота и XP, а модель LoL строится на net worth.
   LoL и с GRID теряет −3.45% на $ покупок (30.08–27.09).
2. **Тейкер не работает.** У обоих агентов все проверенные правила в минусе при любом лаге (0–15 с) и размере ($100–1 000).
3. **Мейкеру деньги даёт частота обновлений, а не задержка.** GRID с обновлением каждую секунду дал бы
   почти вдвое больше: $16 369 против $8 706 при ступени $500.
4. **«PandaScore» против «GRID сегодня»:** +$17.96 на карту при $500 и +$34.70 при $1 000.
   На ~260 картах GRID в месяц это ~$4 670 и ~$9 020 против цены $4 561. Нижние границы интервалов ниже цены.
5. **При живом клипе $60 прогонов нет.** Запуск 1 оценил прирост при текущем клипе в $0.3–1.5 тыс. в месяц.
   Он учитывал только задержку, не частоту.
6. **Главное не проверено:** шлёт ли PandaScore net worth каждую секунду. Это первое, что нужно замерить на пробе.
7. **Oddin уже шлёт состояние каждую секунду** (лаг 15 с). Прогона «Oddin» ещё нет. Если он близок к «PandaScore»,
   на картах с обоими фидами Oddin лучше GRID. `source_picker.py` сейчас выбирает фид по задержке.
8. **Проба:** BLAST Slam VIII (29.09–11.10) или 12–25.11. Окно для оплаты: 12.11–11.12
   (1win Essence III, BLAST Slam IX, DreamLeague 30, ~291 премиальная карта).

## Что покупается

| пункт | факт |
|---|---|
| задержка | «меньше 5 с от события» (док Dota), «~5 с от игрового сервера» (условия, п. 2.5). Независимых замеров нет |
| «на 3–4 минуты быстрее» | это против Twitch и YouTube, не против GRID |

| поля Dota | таймер, пауза; по команде: убийства, net worth, башни, бараки, Рошаны; по игроку: net worth, alive, герой. **XP нет** |
| поля LoL | таймер; по команде: убийства, башни, ингибиторы, драконы, бароны; драфт. **Золота и XP нет** |
| покрытие Dota 2026 | все tier S и A (TI, EWC, ESL One, DreamLeague, BLAST, PGL, FISSURE, 1win Essence), большая часть B/C. Нет: EPL World Series SEA (0/30), BetBoom Streamers Battle, Asgard (2/14) |

- Нехватка XP в Dota не мешает: карты Oddin в лайве уже идут на модели без XP (`production-noxp`).
- Polymarket сам ставит `eventMetadata.pandascoreMatchId` на 45% рынков на карты Dota 2026 года, `gridSeriesId` — на 23%.
  На TI 2026 GRID id был у 0 из 68 событий, PandaScore id — у 58.
- 94% объёма Dota на Polymarket за 2026 год пришлось на турниры с LLF.

| «Идеальный фид» | 0 с | 1 с | есть | с XP, лаг 0 (20260927T214312Z) | `z0-full-b0-l*` |

## Тейкер

| | taker-grok | taker-luna |
|---|---|---|
| правило | одиночные убийства, лимит mid + 2¢, выход через 60 с | все убийства, лимит mid + 5¢, срок выхода с первой половины |
| L = 0, $100, в месяц | −$4 720 | −$41 910 |
| L = 5 с, $100, в месяц | −$4 175 | −$42 000 |
| L = 0, $1 000, в месяц | −$40 456 | −$355 480 |
| верхняя граница (выход по mid) | −$363 | −$12 750 |
| тейкер по модели, L = 0, $100 | −$465 | не считала |

- Ни один вариант сетки не в плюсе (у grok — 0 из 540).
- Сдвиг цены к убившей команде в среднем: +1.2–1.4¢ через 10 с, +2.4–2.7¢ через 60 с. Средний спред 3.7¢.
  Комиссия на вход и выход около 2.5¢ при цене 50¢ (`0.05·p·(1−p)` за акцию).
- Старый ask к 1 с исчезает в 12% случаев, к 4.4 с — в половине.
- На лучшем ask в медиане $58–80. Заявка на $1 000 проскальзывает на 5.93¢ за акцию.
  У 75% событий в пределах +2¢ от лучшего ask меньше $1 000.
- Прошлые попытки тейкера тоже в минусе: Track B (9c653811), P0 (838d9aa8), market-edge (282a69dd, −$46.64 на 404 картах).

4. Абсолютный P&L бэктеста против лайва: п. 1 аудита, `.analysis/dota-audit-2026-09-26/fixes/plans/01-backtest-vs-live.md`.

## Как повторить

Из `esports-trader`, `O=../betting_workspace/.analysis/taker-zero-lag-2026-09-27/work/orchestrator`:

- Очереди целиком: `$O/overnight/run_overnight.sh` (подготовка, обучение, 6 прогонов) и `run_overnight_2.sh`
  (`grid-v1`, 3 сида). Движок пишет в `data/backtests/dota_maker/`. После прогона я перенёс папки
  в `data/experiments/zero-lag/backtests/`, иначе они пачкают дерево git.
- Попарное сравнение: `EDITION="Esports World Cup 2026" uv run python $O/overnight/paired.py A:B`.
  Сиды усредняются через `+`, `EDITION=!<имя>` исключает турнир.
