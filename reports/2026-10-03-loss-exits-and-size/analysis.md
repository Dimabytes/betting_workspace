## Размер позиции

Лимит на карту `LIVE_DOTA_MAX_POSITION_LEVELS = 9` считает купленное и стоящие BUY в ступенях клипа. Клип BLAST Slam — $400, значит лимит $3,600.

## Рекомендации

1. Поставить `LIVE_DOTA_MAX_POSITION_LEVELS = 4`. Максимум на карту станет $1,600 при клипе $400. Ожидание по бэктесту: около 75–79% прибыли при просадке на 38% меньше.
2. Не торговать руками на рынке, где работает бот. Ручные ставки делать с отдельного кошелька. Бот продаёт любые акции своего токена.
3. Halt-баг закрыт коммитом `a47c27e8`. Сейчас дневной лимит фактически выключен. Если нужен дневной стоп, он должен считать только реализованный убыток и запрещать только новые входы.
4. Запрет повторного входа после убыточного выхода на той же карте прогнать в бэктесте.
5. Лимит, который зависит от волатильности, прогнать в бэктесте.
6. Для роста прибыли распределять риск по большему числу карт, а не держать $3,600 на одной. Другие турниры идут на клипе $5. На live прибыль на $100 покупок положительна во всех лигах (от +1.7 до +7.4), но там клипы были маленькие.

## Ограничения

- Бэктест здесь не перезапустить: `validation_dataset.parquet` лежит только на Mac. Цифры по лимитам — оценка урезанием сделок.
- Live-выборка с большим клипом — 38 карт и 8 серий BLAST. Это мало.
- Ребейт — оценка по `session.jsonl`, не выплата.
- 57 live-карт без победителя в `match.json` не вошли в расчёт.

## Как повторить

Скрипты лежат в этой папке. Запуск из папки: `uv run --project /root/work/esports-trader python <script>`.

1. `load_live.py`, затем `analyze_live.py`: карты и сделки live.
2. `exits_live.py`, `live_episodes.py`, `live_vol.py`, `live_caps.py`, `today_table.py`: live-срезы.
3. `fetch_res.py`: победители карт бэктеста в `resolutions.json`.
4. `bt_exits.py`, `bt_episodes.py`, `bt_caps.py`: срезы бэктеста.
5. `validate_trunc.py`, `validate_risk.py`: проверка метода урезания.
