# Exa

> Exa is a real-time knowledge index and retrieval platform built for AI agents. Exa builds and maintains its own index and search models, and continuously indexes the live web alongside structured data about companies, people, financial markets, code, documents, and other sources. Developers use Exa's APIs to search, retrieve, and research public and private data.

**Start for free:** New accounts receive $20 in free credits and $10 in free credits every month. No payment method is required, and the free tier includes access to all API endpoints.

For AI agents and automation, start with the agent-native interfaces below. For complete technical documentation, use the Exa documentation index.
