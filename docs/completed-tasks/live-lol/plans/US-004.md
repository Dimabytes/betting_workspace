## 3. File-level changes

### 3.1 Create `src/live_paper/game_profile.py` (only production file)

Verified: this path does not exist. `src/live_paper/` has no `__init__.py`; do not add one.

Module docstring, then imports at top:

```python
from dataclasses import dataclass
from pathlib import Path

from shared.constants.dota import LEVEL_XP
from shared.constants.lol import LOL_LEVEL_XP, LOL_PRODUCTION_MODEL_DIR
from shared.constants.paths import PRODUCTION_MODEL_DIR
from shared.constants.strategy import MAX_ABS_NW_DELTA_30
```

`@dataclass(frozen=True)` — **not** `slots=True` (live-lol plan and most live_paper types omit slots). One- or two-line class docstring. Field order **exactly**:

1. `game: str`  — values `"dota"` / `"lol"`. `Literal["dota", "lol"]` is allowed (stricter, not a factory) if basedpyright stays happy; do not introduce a second type alias / enum / registry.
2. `archive_root_env: str`
3. `mode_env: str`
4. `level_xp: tuple[int, ...]`
5. `side_0_text: str`
6. `side_1_text: str`
7. `profile_name: str`
8. `production_model_dir: Path`
9. `uses_steam: bool`
10. `max_abs_nw_delta_30: float | None`

No default values. No `field()`. No methods on `GameProfile`. No `get_profile`, `load_profiles`, `build_*`, entry points, or `GameProfileRegistry`.

Then a static dict (this is the mapping the live-lol plan names; `dict[str, GameProfile]` is typed, not `dict[str, Any]`):

```python
GAME_PROFILES: dict[str, GameProfile] = {
    "dota": GameProfile(
        game="dota",
        archive_root_env="DOTA_ARCHIVE_ROOT",
        mode_env="DOTA_TRADING_MODE",
        level_xp=LEVEL_XP,
        side_0_text="RADIANT",
        side_1_text="DIRE",
        profile_name="dota-map",
        production_model_dir=PRODUCTION_MODEL_DIR,
        uses_steam=True,
        max_abs_nw_delta_30=MAX_ABS_NW_DELTA_30,
    ),
    "lol": GameProfile(
        game="lol",
        archive_root_env="LOL_ARCHIVE_ROOT",
        mode_env="LOL_TRADING_MODE",
        level_xp=LOL_LEVEL_XP,
        side_0_text="BLUE",
        side_1_text="RED",
        profile_name="lol-map",
        production_model_dir=LOL_PRODUCTION_MODEL_DIR,
        uses_steam=False,
        max_abs_nw_delta_30=None,
    ),
}
```

Pass the imported tuples/Paths/float **by identity** (`level_xp=LEVEL_XP`, not `tuple(LEVEL_XP)` / not a copied list). Do **not** wrap `GAME_PROFILES` in `MappingProxyType` (unused in this repo; the spec is a static dict). Do not freeze the dict itself.
