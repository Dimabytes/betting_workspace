### 1.2 Telonex local tree today

`src/backtest/telonex_local.py`:

- Capture root is the module constant `RAW_TELONEX_POLYMARKET_DIR` (`data/raw/telonex/polymarket`).

### 3.3 `lol_inputs.py`

Read only local Stage 07 + Gamma cache + model.json. No network.

**Selection**

- `--validation`: audit rows with `eligible==True`, stable sort `event_id, match_id` (same as Stage 07 publish). That ordered tuple is the paired map set for every arm. `--limit` slices it.
- Ineligible audit rows do not enter replay. Map counts into existing `ValidationCoverage` so `log_coverage` / summary stay on the Dota dataclass (no LoL coverage type, no new report fields):

|---|---|

Other Stage 07 reasons (`missing_livestats`, `missing_cutoff_midpoint`, …) sit in `validation_matches - eligible - the two mapped buckets`. Do not add fields. Do not invent a LoL status.

- `--match-id`: that int must appear in signals and be `eligible`. Else `ValueError` naming the id. Do not silently run a Dota OpenDota match.

**Lag gate (runner, not a silent cache rebuild)**

1. `read_model_meta(model_dir / "model.json")["source_lag_seconds"]`.
2. Stage 07 audit `source_lag_seconds` must be a single value equal to that int.
3. That int must equal `LOL_SOURCE_LAG_SECONDS` (25).

Mismatch → `ValueError` before replay / before publish of a new manifest. Do not call Stage 07. Do not apply `lagged_source_features`.

**Context per eligible id**

- `match_id`, `condition_id`, `event_id`, `market_slug` (audit `slug`), `token_ids=(token_id_0, token_id_1)`, `radiant_token_index`, `radiant_win` from audit.
- `horn_at` = spawn = `replay_start` + `LOL_REPLAY_LEAD` (`replay_start_ts` is unix seconds).
- `game_ended_at` / `replay_start` / `replay_end` from audit ts.
- `seconds_delay` / `market_closed_at` from `index_gamma_markets(LOL_RAW_GAMMA_DIR / "events")[condition_id]`. Missing page → `ValueError` (eligible card must be replayable).
- `clock_end = calculate_clock_end(game_ended_at, market_closed_at)` — same helper as Dota. US-004 may change settlement later; do not change it here.

**Pauses for shared `build_strategy_configs`**

Need `get_state_available_ts(horn_at, BUY_CUTOFF_SECOND, pauses) == pause-adjusted wall of second 540` (or last market second if the map ended earlier).

Market-second `state_ts_us` at second S **is** that wall. Let `cut = min(540, max market second for the match)`, `wall = datetime from that row's state_ts_us`, `extra = int((wall - horn_at).total_seconds()) - cut`. If `extra > 0`, one synthetic `OpenDotaPause`: `{"time": 0, "duration": extra}`. If `extra == 0`, empty list. If `extra < 0`, raise (Stage 07 clock bug). Do not re-read lolesports windows.

**Mids**

Filter Stage 07 `market_seconds` the same way Dota does: `market_status == "ok"` and non-null `market_p_radiant`; `state_ts_us * NS_PER_US`. Group by `match_id`. Missing series for a requested id → `ValueError`.

**Signals**

`build_match_signals(..., lag_seconds=0)` on Stage 07 signal rows for those ids. Reuse `calculate_nw_deltas_30`. Strategy field names unchanged.
