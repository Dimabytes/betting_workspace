## Matching algorithm

Reuse `normalize_team_name`, `score_team_name`, `pick_pair_orientation`, `PAIR_SCORE_MIN` (0.82), `SIDE_SCORE_MIN` (0.72) from `src/shared/utils/team_names.py`. Do not copy Dota's OpenDota series state machine. Do not pick the nearest time among multiple eligible series.

### Inputs

1. All `LolUniverseMarketRow` from `markets.parquet`.
2. All `LolGameRow` from `games.parquet`, grouped by `esports_match_id` into a frozen `LolSeries` (`match_id`, `start_ts`, `best_of`, `league_slug`, `league_name`, two teams with id/name/code, final `game_wins`, completed maps in `game_number` order).

### Event context

Consider event ids that have **at least one `included=True` row**. Build one frozen `EventContext` per such event from **all** rows of that event (included and excluded): `team_a`, `team_b`, `best_of`, `league`, `scheduled_ts`, explicit Game N markets (`contract_kind == "game_winner"` keyed by `game_number`), Match Winner rows (`contract_kind == "match_winner"`). Skip the event with `reason=missing_teams` if either team is null; `reason=missing_schedule` if `scheduled_ts` is null. These still get an event-scope audit row.

`explicit_game_n_count` = number of `contract_kind == "game_winner"` rows (used for duplicate resolution, not only included ones).

### Score a PM name against one lolesports team

Observed set = `{name, code}` plus every `LOL_TEAM_ALIASES` expansion of those strings (and of the PM name). Then `score_team_name(pm_name, observed_set)` so Dota `TEAM_ALIASES` still apply. Helper lives in the stage file, not in `team_names.py`.

`LOL_TEAM_ALIASES` is small and permanent in `constants/lol.py`. No per-match overrides. Starter rows (symmetric via scoring both sides):

```python
LOL_TEAM_ALIASES: dict[str, tuple[str, ...]] = {
    "skt": ("t1", "sk telecom t1"),
    "t1": ("skt", "sk telecom t1"),
    "damwon": ("dplus kia", "dk", "dwg"),
    "dplus kia": ("damwon", "dk", "dwg"),
    "dk": ("dplus kia", "damwon", "dwg"),
}
```

Add more only when a test or a real unmatched name needs them. Never hub two opponents onto one key.

### Series eligibility (all applicable guards)

For each `EventContext` × `LolSeries`:

1. `start_ts` and `scheduled_ts` both present; `abs(delta) <= LOL_SERIES_START_WINDOW_SECONDS` (4 * 60 * 60). Else skip.
2. Names: `pick_pair_orientation(score(pm_a, series_a), score(pm_b, series_b), score(pm_a, series_b), score(pm_b, series_a))`. `None` → skip. True means PM A is series team A. This is the 0.82 average / 0.72 per-team rule.
3. BO: if **both** `event.best_of` and `series.best_of` are not None, they must be equal. If either is None, skip this guard (does not reduce coverage).
4. League: canonicalize both sides. If **both** canonicalize to a known slug, slugs must be equal. If either is unknown, skip this guard.

Canonical league: `normalize_team_name(value)`, then `LOL_LEAGUE_ALIASES.get(key)` else `key` if `key` is in `LOL_LEAGUE_SLUGS`, else `None`.

```python
LOL_LEAGUE_SLUGS = frozenset({
    "lck", "lec", "lpl", "ldl", "lcs", "lcp", "worlds", "msi", "nacl", "cblol",
})
LOL_LEAGUE_ALIASES = {
    "lol champions korea": "lck",
    "league of legends champions korea": "lck",
}
```

Include `lpl` and `ldl` in `LOL_LEAGUE_SLUGS` so a later real run can prove Chinese coverage. Tests need `lck` vs `lec` mismatch and unknown-league skip.

Eligible series = those that pass all applicable guards. Do **not** break ties by time.

### Accept / ambiguous / unmatched (event grain)

| eligible count | event `reason` |
|---|---|
| 0 | see miss reason below |
| 1 | tentatively `matched` |
| >1 | `multiple_eligible_series` (ambiguous). Never pick nearest. |

Zero-eligible miss reason, first match:

1. `league_mismatch` — ≥1 series passed names+time+BO but failed the league guard.
2. `bo_mismatch` — ≥1 series passed names+time but failed the BO guard (and not already league).
3. `no_candidates_in_window` — otherwise.

### Duplicate PM events claiming one series

After the unique-candidate pass, group tentatively matched events by `esports_match_id`.

- One claim: keep matched.
- Several claims: let `n` = `explicit_game_n_count`. Unique max `n` wins. Losers: event reason `series_claimed_by_richer_event`, `duplicate_of` = winner event id, proposal cleared (no links).
- Tied max `n`: **all** claimants (including the tied richest) become `series_claim_tie` / ambiguous. No winner.

### Map assignment (only accepted series)

For each completed map in the series, in `game_number` order:

1. If an **included** `game_winner` row exists for that `game_number` → assign it (`assignment=game_winner`).
2. Else if a `game_winner` row exists but is not included → map reason `unresolved_market` when its universe reason is that, else `no_market`. Do **not** fall through to Match Winner (`series_winner_covers_map(..., map_winner_exists=True)`).
3. Else if `series_winner_covers_map(best_of, game_number, map_winner_exists=False)` **and** `decider_score_is_tied(best_of, team_a_game_wins, team_b_game_wins)` **and** an **included** Match Winner row exists → assign it (`assignment=match_winner_decider`).
4. Else if a Match Winner row exists but the Stage 03 decider guards fail → `unsupported_fallback`.
5. Else if a Match Winner row exists but is not included → `unresolved_market` or `no_market` from its universe reason.
6. Else → `no_market`.

`series_winner_covers_map` is imported from `shared.constants.dota` (do not duplicate). Stage 01 already allowed BO1/BO3/BO5 Match Winner onto the parquet; Stage 03 additionally requires the map to have been played (it is in `games.parquet`) and the final series score to be a real decider:

```text
max(wins) == best_of // 2 + 1  and  min(wins) == max(wins) - 1
```

BO1 → `(1, 0)`. BO3 → `(2, 1)`. BO5 → `(3, 2)`. A 2-0 BO3 has no completed Game 3 in `games.parquet`; if a Game 3 row appeared anyway, step 4 rejects it.

Assigned market must have a non-null `condition_id` and `resolved_outcome` / `resolved_outcome_index`. Missing resolution after assignment is `unresolved_market` (should not happen for `included=True`; still guard).

### Orientation (only assigned maps)

Chain from design §6.4:

1. Parse `outcomes_json` → `outcome_0`, `outcome_1` (Gamma order, same as tokens).
2. Score the two outcomes against the two **series** team name/code sets with the same matcher / `pick_pair_orientation`. `None` → map reason `orientation_ambiguous`.
3. Winning orientation maps each outcome to one `esportsTeamId` (`team_a_id` or `team_b_id`).
4. Look up that id in this map's `blue_esports_team_id` / `red_esports_team_id`. Outcome whose team id equals blue → Blue.
5. `radiant_token_index = 0` if outcome 0 is Blue, else `1`.
6. If the two teams are not exactly `{blue_id, red_id}` (missing side, both blue, id not on this map) → `missing_side`.

Ambiguous orientation excludes the map. It does not un-match the rest of the series.

## getSchedule pagination, cache, games build

### API (design §6.1)

```text
GET https://esports-api.lolesports.com/persisted/gw/getSchedule?hl=en-US
    [&pageToken=<pages.older|pages.newer>]
GET https://esports-api.lolesports.com/persisted/gw/getEventDetails?hl=en-US&id=<matchId>
header x-api-key: 0TvQnueqKa5mxJntVWt0w4LpLfEkrV1Ta8rQBb9Z

GET https://feed.lolesports.com/livestats/v1/window/<esportsGameId>
```

Key is public (embedded in lolesports.com JS). Store as `LOLESPORTS_API_KEY` in `constants/lol.py`, not in `.env`. Window feed takes **no** key. Do not call `/details`. Do not pass `leagueId` (must see LPL/LDL). `hl=en-US` is required.

Local fetch (stage file): `client.get` with per-request headers. **Do not call `get_json`.** On 401/403 raise `RuntimeError` immediately (no retry, do not write cache). On 429/5xx bounded backoff (tenacity, 5 attempts). Other 4xx: 404 on a single event/window is a skip for that id, not a run abort.

### How far back / forward

Read universe first. `gamma_min_ts` / `gamma_max_ts` = min/max of non-null `scheduled_ts`. Missing universe file or no timestamps → `RuntimeError`.

Window pad = `LOL_SERIES_START_WINDOW_SECONDS`.

1. First `getSchedule` with no `pageToken` (current schedule).
2. Follow `data.schedule.pages.older` while the page's **newest** `startTime` is still `>= gamma_min_ts - pad`. After a page whose newest start is older than that, stop (that page is still cached).
3. If the first page's **oldest** start is still `<= gamma_max_ts + pad`, follow `pages.newer` until the page is entirely after `gamma_max_ts + pad`.

Do not filter by league. Dedup schedule events by `match.id`.

### Cache layout

```text
data/lol/raw/lolesports/
  schedule/page_00000.json.gz
  events/<matchId>.json.gz
  anchors/<esportsGameId>.json
```

Schedule pages: gzip JSON, `mtime=0`, envelope `{endpoint, page_token, pages, fetched_at, body}` where `body` is the provider object. `--fetch` writes the whole schedule tree into `staging_directory` then `install_staged_directory` (same as US-001 Gamma). Never replace with a partial tree.

Events/anchors: one file per id, **resume**. Skip HTTP when the file exists and passes the top-level schema check. New files: write `.tmp` / `.partial` then replace. Gzip events; anchors stay `.json` as in the design.

`--fetch` downloads; without `--fetch`, rebuild parquets from cache. Missing schedule page or missing event/anchor for a completed schedule match without `--fetch` → `RuntimeError`.

### What to fetch from a schedule event

Keep `type == "match"` and `state == "completed"` only. Load `getEventDetails`. From `data.event.match`: `strategy.count`, `teams[]` (`id`, `name`, `code`, `result.gameWins`), `games[]` (`number`, `id`, `state`, `teams[].side` + `esportsTeamId`).

Per game with `state == "completed"`: GET window **without** `startingTime`. Loading anchor = min `rfc460Timestamp` over `frames`. Empty `frames` → skip that game (no `games.parquet` row, not fatal). HTTP 404 → skip that game. Missing blue or red `esportsTeamId` → skip that game (cannot orient later).

`games.parquet` is rebuilt fully from caches every run (cheap).

### Expected top-level schema (abort if wrong)

**getSchedule:** object with `data.schedule.events` a list and `data.schedule.pages` an object (`older`/`newer` may be null).

**getEventDetails:** object with `data.event.match` an object containing `teams` and `games` lists.

**window:** object with `esportsGameId` a string and `frames` a list. `gameMetadata.patchVersion` may be absent (store null). Do not abort on extra keys.

Incompatible schema: `RuntimeError`, do not cache that body, do not continue paging.

CLI:

```text
uv run python src/lol/03_link_lolesports.py --fetch
uv run python src/lol/03_link_lolesports.py
```

`--universe-path`, `--raw-dir`, `--games-path`, `--links-dir` default to LoL constants; tests pass tmp paths into functions (required args). Always publish parquets (no `--publish` flag). Empty `links.parquet` is allowed (print zeros); empty universe is not.

After write, `print_count` at least: `schedule_matches`, `games`, `pm_events`, `accepted_links`, and every audit `reason`.

## HTTP 403 / incompatible-schema abort

| condition | behavior |
|---|---|
| HTTP 401 or 403 (esports-api or livestats) | `RuntimeError` immediately. No tenacity retry. Do not write that cache file. Nonzero exit. |
| Top-level schema mismatch | `RuntimeError` with endpoint name. Do not write that cache file. Stop the run. |
| Duplicate `esports_game_id` in games or links; duplicate `(event_id, game_number)` in links | `RuntimeError` before replace. |
| HTTP 404 / empty frames on one window or event | Skip that id; continue. |
| HTTP 429 / 5xx / transport | Retry with bounded backoff; then raise. |
| Unmatched / ambiguous / orientation / fallback | Audit row only. Run continues. |

`get_json` retries `raise_for_status()` including 403. That is why the stage owns its client calls. Shared `http_client()` User-Agent is fine; add `x-api-key` only on esports-api requests.
