## Key design decisions

### `markets.parquet` schema

One row per Gamma market, included and excluded. Column names are snake_case (matches `DatasetRow`, not Dota `conditionId`). TypedDict `LolUniverseMarketRow`:

| column | type | meaning |
|---|---|---|
| `event_id` | `str` | PM event id |
| `event_slug` | `str \| None` | event slug |
| `market_id` | `str \| None` | Gamma market id |
| `condition_id` | `str \| None` | CLOB condition id; None only when missing |
| `question` | `str \| None` | market question |
| `group_item_title` | `str \| None` | Gamma `groupItemTitle` |
| `sports_market_type` | `str \| None` | Gamma `sportsMarketType` |
| `outcomes_json` | `str` | JSON list of outcome labels, **Gamma order** |
| `clob_token_ids_json` | `str` | JSON list of token ids, **same order as outcomes** |
| `team_a` | `str \| None` | first PM team |
| `team_b` | `str \| None` | second PM team |
| `game_number` | `int \| None` | Game N, or decider map `== best_of` |
| `best_of` | `int \| None` | parsed BO |
| `league` | `str \| None` | `eventMetadata.league` else title suffix after `(BOx) - ` |
| `scheduled_time` | `str \| None` | UTC Z from event `startTime` or market `gameStartTime` |
| `scheduled_ts` | `int \| None` | unix seconds |
| `market_start_time` | `str \| None` | market `startDate` UTC Z |
| `market_end_time` | `str \| None` | market `endDate` UTC Z |
| `resolved_outcome` | `str \| None` | winning outcome **label**, only when resolved |
| `resolved_outcome_index` | `int \| None` | `0` or `1` in original order, only when resolved |
| `contract_kind` | `LolContractKind` | `game_winner` / `match_winner` / `other` |
| `included` | `bool` | True only for structurally valid + resolved rows |
| `reason` | `str` | exactly one stable constant from the list below |

Integer parquet columns `game_number`, `best_of`, `scheduled_ts`, `resolved_outcome_index` use pandas `Int64`. Sort by `(scheduled_ts, event_id, condition_id)` with nulls last. Duplicate non-null `condition_id` is fatal (`RuntimeError`), per design §11.

Write through a temp sibling then `Path.replace` (design §11). Do not add a shared atomic-parquet helper this step.

### Contract classification and reasons

Stable strings in `src/shared/constants/lol.py`. `reason` is never empty. Tests assert `sum(reason counts) == len(rows)`.

**Included** (`included=True`):

- `game_winner` — explicit Game N Winner, tokens/outcomes valid, not BO2, resolved 1/0.
- `match_winner_decider` — Match Winner allowed as decider fallback, tokens/outcomes valid, resolved 1/0.

**Excluded** (`included=False`), first matching gate wins:

1. `malformed_tokens` — not exactly two distinct nonempty token ids **and** two nonempty outcome labels.
2. `unsupported_contract` — not Game N Winner and not Match Winner (futures, scoreline, season, etc.).
3. `unsupported_bo2` — event BO is 2 (Game N and Match Winner both out).
4. `series_only` — Match Winner on BO3/BO5 whose event has **zero** explicit Game N markets.
5. `missing_best_of` — Match Winner but BO could not be parsed (cannot apply the decider rule).
6. `unresolved_market` — passed gates 1–5 (structurally supported) but Gamma prices are not a strict 1/0 pair.

Do **not** exclude Match Winner just because an explicit Game N for the decider map also exists. Stage 03 prefers Game N (`series_winner_covers_map(..., map_winner_exists=True)`). Stage 01 still records the Match Winner as `match_winner_decider` when the event is not series-only.

Game N classification (first hit):

- question matches `\bGame\s*(?P<game_number>\d+)\s+Winner\b`, or
- `sportsMarketType` lowercased is `child_moneyline` (game number from the question if present).

Match Winner classification (only if not Game N):

- `sportsMarketType` lowercased is `moneyline`, or
- question matches `\bMatch\s+Winner\b`.

Everything else is `other` → `unsupported_contract`.

Decider fallback (design §4.1), using existing `DECIDER_BEST_OF` and `series_winner_covers_map` from `src/shared/constants/dota.py`:

- BO1: Match Winner represents Game 1 (`game_number=1`). No Game N on the event is required.
- BO3: Match Winner represents Game 3 (`game_number=3`) only when the event has at least one Game N market (otherwise `series_only`).
- BO5: same for Game 5.
- BO2: `unsupported_bo2`.
- “Actually played” / tied series score is **Stage 03**, not this step.

Event-level facts (compute once per event, then classify each market): `best_of`, teams, league, `has_game_winner: bool`.

Teams: two structured `event.sports.teams` names if both nonempty; else parse `LoL: A vs B (BOx)` from the title. Do not call `team_names.py` here (US-002).

BO: `\(BO\s*(\d+)\)` on the title, else `Bo(\d+)` in `event.sports.score` (same idea as Dota score text, LoL regex next to this stage).

### Resolution rule

Use SDK `Market.outcomes.yes.price` and `.no.price` (`Decimal | None`), which are `outcomePrices` in Gamma order.

Resolved iff **exactly one** price equals `Decimal("1")` and the **other** equals `Decimal("0")`. Compare Decimals, not floats.

Unresolved (keep the row, `reason=unresolved_market`) includes: open market, both live, `1/1`, `0/0`, `1/0.01`, missing price, unfinished UMA, any other pair. `resolved_outcome` / `resolved_outcome_index` stay null.

Apply this gate only after the contract is structurally supported. A futures market with 1/0 is still `unsupported_contract`, not `unresolved_market`.

### Gamma pagination and raw cache

Endpoint: `GET {POLYMARKET_GAMMA_API}/events/keyset` (already used by Dota; reuse `shared.constants.api.POLYMARKET_GAMMA_API`, `get_json`, `http_client`).

Two cursor chains, `limit=500`:

| source | filters |
|---|---|
| `tag_65_closed` | `tag_id=65`, `closed=true` |
| `tag_65_open` | `tag_id=65`, `closed=false` |

Cache layout (isolated, envelope = existing `UniverseEventsPage` so `read_polymarket_universe_page` works):

```
data/lol/raw/polymarket/gamma/events/
  tag_65_closed/page_00000.json.gz
  tag_65_open/page_00000.json.gz
```

Each page: gzip JSON, `mtime=0`, fields `endpoint`, `source`, `query`, `request_cursor`, `next_cursor`, `fetched_at`, `events`. No Dota `--as-of` stamp this step: the cache is the raw snapshot; parquet rebuilds from whatever is on disk.

Fetch into `staging_directory`, validate each chain (cursor progression, no repeated cursor, no empty page with `next_cursor`, no duplicate event id inside a chain), then `install_staged_directory` onto `.../gamma/events`. Never replace raw with a partial tree.

CLI: `--fetch` downloads; without `--fetch`, rebuild parquet from cache or `RuntimeError` if no pages. `httpx` 401/403/`raise_for_status` already abort. Repeated Gamma cursor is fatal. Event parse failure (SDK `UnexpectedResponseError` on the event object) is fatal schema change (design §11).

### How to walk markets without silent SDK drops

`Event.parse_response` **drops** markets whose `outcomes` length ≠ 2 (`_normalize_event_market` returns `None`). That is a silent drop. Do not classify from `event.markets` alone.

For each cached page:

1. Load gzip JSON (`shared.utils.json_io.read_gzip_json` or the universe-page reader for envelope checks).
2. For each raw event dict: `Event.parse_response(raw_event)` for event-level fields (id, slug, title, teams, score, schedule, `metadata` ← `eventMetadata`).
3. Iterate `raw_event["markets"]` as a list. Per market: try `Market.parse_response`; on failure or missing tokens still emit a row with `malformed_tokens` (pull `id` / `conditionId` / `question` from the raw dict when present).

A market that exists in Gamma JSON always becomes a parquet row.

### Totals

After write, print with `print_count` (plus one line per reason, sorted by reason name):

- `events`
- `markets` (row count)
- `included`
- each `reason` count

Test: printed/returned reason histogram sums to `markets`. No market may exist in input JSON and vanish from the frame.
