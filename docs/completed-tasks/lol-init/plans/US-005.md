## Telonex API flow

All of this is copied semantics, not a new API design.

### Catalog

```
GET https://api.telonex.io/v1/datasets/polymarket/markets
```

- Public parquet (deleted script streamed it with **no** Bearer). Still abort the run on HTTP 401/403 if they appear. Retry transport / 429 / 5xx with the same bounded backoff as book downloads.
- Not paginated: one parquet blob. "Stream" means HTTP `iter_bytes(1 MiB)` to a temp file, then `pq.ParquetFile.iter_batches`, then delete the temp. Do not `pd.read_parquet` the full catalog (multi-GB).
- Temp path: `LOL_RAW_TELONEX_DIR / "markets.full.parquet.partial"` then rename to `markets.full.parquet` for the slice read; **always unlink** the full file in `finally` after a successful slice. Do not keep tags.parquet. Do not hash the catalog into artifacts.
- Required columns missing or `market_id` absent from schema → `RuntimeError` (design §11 catalog schema change). Do not guess alternate names.
- Slice: keep rows whose `market_id` is in the included-universe condition-id set. Telonex `market_id` **is** Gamma `conditionId` (deleted `parse_gamma_market`). Duplicate `market_id` in the slice is fatal.
- Write the filtered batches with original provider schema via `pq.ParquetWriter` through `.tmp` + `Path.replace` to `catalog.parquet`. Empty slice is a valid parquet (0 rows) and then every included market audits as `missing_from_catalog`.

### Book download (compare_collector_to_telonex.py)

```
GET https://api.telonex.io/v1/downloads/polymarket/book_snapshot_full/YYYY-MM-DD
    ?asset_id=<token_id>
Authorization: Bearer <TELONEX_API_KEY>
```

- `follow_redirects=True`. Timeout `httpx.Timeout(120.0, connect=30.0)`. User-Agent `dota-2-model/0.1 lol-telonex`.
- Query by `asset_id` (token id), **not** `slug`+`outcome_id` (that is the backtesting library; do not copy it).
- Stream 1 MiB chunks into `<date>.parquet.partial`, validate, then `partial.replace(target)`.

### Date intervals

Catalog columns `book_snapshot_full_from` / `book_snapshot_full_to` are a half-open UTC window: **from inclusive, to exclusive**. Deleted `expand_dates`:

- `("2026-08-01", "2026-08-03")` → `("2026-08-01", "2026-08-02")`
- `from == to` or `to < from` or either empty → no days
- Normalize catalog values to `YYYY-MM-DD` first (date32 / timestamp / `2026-01-20T05:00:00Z` → UTC date, then `.isoformat()`). Do not treat `to` as inclusive (the Nautilus downloader does; that is wrong here).

### Book parquet columns

Provider file, untransformed. Skip/accept validation requires footer + all of `TELONEX_BOOK_REQUIRED_COLUMNS` + every non-null `asset_id` cell equal to the path token. Zero-row parquet with the schema is valid. `telonex_book.py` later reads `timestamp_us`, `bids`, `asks` only.

## Validation, `.partial`, atomic replace

Copy `validate_target` from the deleted script (book channel only). Do **not** quarantine: invalid existing file is treated as missing and overwritten via `.partial` + replace.

Skip HTTP only when `validate_target(target, asset_id).valid`. Otherwise:

1. Unlink leftover `target.with_suffix(target.suffix + ".partial")`.
2. Stream into that `.partial`.
3. `validate_target(partial, asset_id)`; on failure unlink partial and retry (bounded).
4. `partial.replace(target)`.

Catalog slice and audit parquet use `.tmp` + replace (reuse `write_parquet_rows` for audit only).

## Retry / backoff / abort

Same status policy as `compare_collector_to_telonex.download_one`, with the deleted script's **actual sleep** (compare busy-loops; design requires backoff):

| Condition | Behavior | Audit `reason` |
|---|---|---|
| `httpx.TransportError`, `TimeoutException`, HTTP 429, HTTP 5xx | retry up to `TELONEX_MAX_ATTEMPTS`, `sleep(min(60, 2**attempt) + random())`; on 429 honor `Retry-After` capped at 120s | after exhaust: `retries_exhausted`, continue other jobs |
| HTTP 401 / 403 | `FatalDownloadError` / `RuntimeError`, abort run, do **not** write audit parquet | — |
| HTTP 404 | no retry, this job fails | `http_404` |
| Other 4xx | abort run (cannot classify) | — |
| valid existing file | no HTTP | `skipped_valid` |
| downloaded + validated | — | `downloaded` |

`ThreadPoolExecutor(max_workers=6)`, one future per job, shared `httpx.Client`. On 401/403: `shutdown(wait=False, cancel_futures=True)` and re-raise. In-flight `.partial` files stay for resume.

After all jobs: write audit, print counts, `raise typer.Exit(1)` if any row has `complete=False`.

Tests must `monkeypatch.setattr("time.sleep", lambda _: None)`.

## `download_audit.parquet` schema

TypedDict `LolTelonexAuditRow`. Integer columns pandas `Int64`. Write via Stage 03 `write_parquet_rows`. Sort `(condition_id, asset_id, date)` with nulls last.

| column | type | meaning |
|---|---|---|
| `condition_id` | `str` | Gamma / Telonex `market_id` |
| `asset_id` | `str` | token id; `""` on market-level misses |
| `date` | `str \| None` | UTC day; null on market-level misses |
| `row_count` | `int` | parquet rows (0 if not on disk) |
| `complete` | `bool` | True iff `reason` is `downloaded` or `skipped_valid` |
| `reason` | `str` | exactly one of the seven reason constants |

Grain:

- Downloadable market: one row per `(asset_id, date)` job.
- `missing_from_catalog` / `token_id_mismatch` / `missing_interval`: one market-level row, no day jobs.

Print totals via `print_count` for each reason plus `included_markets` and `jobs`.
