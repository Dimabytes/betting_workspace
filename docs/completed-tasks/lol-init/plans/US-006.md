## Frame pipeline (`livestats_frames.py`)

Raw archive: `windows_dir / f"{esports_game_id}.jsonl.gz"`. Missing/invalid gzip → map drop `no_livestats`. Read with `read_gzip_jsonl`. Each line is a window object with `frames`.

### Dedup / sort

Keep the full frame dict. Key = `rfc460Timestamp` string. Overlapping 10s windows duplicate stamps: last write wins (payloads are the same object). Sort by parsed wall seconds. Drop frames with unparsable stamps.

### Spawn clock zero (design §8.1)

`spawn_frame` = first frame where any participant `totalGold > 0` (`frame_has_gold`). `game_start_wall` = that frame’s rfc460 wall.

- No such frame, or its wall is more than `LOL_SPAWN_SEARCH_SECONDS` after `link.loading_anchor_ts` → `no_spawn_frame`.
- Loading→spawn gap is **not** a pause. Pause scan starts at the spawn frame.

`start_time` (DatasetRow) = `floor(game_start_wall_ms / 1000)` with `game_start_wall_ms = round(spawn_wall_seconds * 1000)`.

`match_id` = `int(esports_game_id)` (18-digit decimal, fits signed 63-bit).

### Pause subtraction (design §8.2–8.3)

Copy Stage 04 `max_game_second` arithmetic, after dedup, assigning a `game_time` to every post-spawn frame:

```
paused = 0
previous = spawn_wall
for frame in post_spawn[1:]:
    gap = frame.wall - previous
    if gap > LOL_PAUSE_MIN_GAP_SECONDS:   # 5s
        paused += gap
    previous = frame.wall
    game_time = frame.wall - spawn_wall - paused
```

Include the pause that **ends on this frame** (04 already does this; “fully completed before frame_wall” in prose would otherwise leave the first post-pause frame 20s late). Spawn frame `game_time = 0`.

`# ponytail: feed holes >5s are indistinguishable from pauses and shift later seconds; design §8.2 known ceiling.`

### Seven invariants (design §9.6)

Run on the **spawn frame and every later frame** (not pre-spawn loading). One failure drops the whole map with `livestats_invariant_violation`. Record which rule in audit (`invariant_rule` 1..7). Print the map count; if count > `MAX_LIVESTATS_INVARIANT_MAPS`, abort before publish.

1. Spawn frame: all ten players `totalGold == 500`.
2. Each player `totalGold` is non-decreasing vs the previous post-spawn frame (same participant identity: stable `participantId` if present, else slot order inside `blueTeam`/`redTeam`).
3. `team.totalGold == sum(five players.totalGold)` on both sides.
4. `team.totalKills == sum(opponent participants.deaths)` on both sides.
5. Each player `level` is an int `>= 1` and non-decreasing. Level `> 18` is this violation (no cap branch; `cumulative_xp` would raise anyway).
6. Each player `deaths` is non-decreasing.
7. Exactly five participants in `blueTeam` and five in `redTeam`.

Gaps are not an invariant. A gap in `(2, 5]` seconds only drops individual grid rows via the age gate and increments an audit counter.

Missing/non-numeric required fields → same map drop (treat as violation), no silent skip.

### Grid `second = 0, 1, …, 540` (design §9.2)

For integer `S` in `0..540` inclusive:

- Candidate = latest post-spawn frame with `game_time <= S`.
- If none, or `S - game_time > 2`, **drop that second only**. No walk-back, no interpolate, no forward-fill.
- `DatasetRow.second = S` (the grid key, not `floor(game_time)`).
- `state_wall_time` for market join = that frame’s rfc460 wall (microseconds: `round(wall_seconds * 1_000_000)`).

Cap 541 rows per map before market filters. Features come only from the chosen frame.

All twelve names match Dota `FEATURE_COLUMNS`. Game fields from **one** selected frame; Blue = Radiant, Red = Dire (orientation is token-side, not these columns).

| Feature | Source |
|---|---|
| `second` | grid `S` |
| `radiant_nw` | `blueTeam.totalGold` |
| `dire_nw` | `redTeam.totalGold` |
| `radiant_nw_adv` | blue − red team gold |
| `radiant_xp_adv` | `xp_advantage(LOL_LEVEL_XP, blue levels, red levels)` |
| `deaths_radiant` | sum blue `participants[].deaths` |
| `deaths_dire` | sum red `participants[].deaths` |

`radiant_win` = `resolved_outcome_index == radiant_token_index`. Empty/unresolved → map drop `unresolved_market`.

### `level_xp.py` extract (Dota behavior frozen)

```python
def cumulative_xp(level_xp: tuple[int, ...], level: int) -> int:
    """Cumulative XP at `level`. Level 0 is 0 XP (Dota draft)."""
    max_level = len(level_xp)
    if level < 0 or level > max_level:
        raise ValueError(f"level must be between 0 and {max_level}: {level}")
    if level == 0:
        return 0
    return level_xp[level - 1]

def xp_advantage(
    level_xp: tuple[int, ...],
    first_levels: list[int],
    second_levels: list[int],
) -> int:
    """Sum of cumulative XP on `first_levels` minus `second_levels`."""
```

`dota_levels.experience_at_level(level)` returns `cumulative_xp(LEVEL_XP, level)` so existing tests (`0→0`, `1→0`, `30→64400`, reject `-1`/`31`) stay green without edits. LoL calls `cumulative_xp(LOL_LEVEL_XP, level)` / `xp_advantage(LOL_LEVEL_XP, blue, red)` only.

## Market data (design §9.5, §9.7)

Tokens: `json.loads(clob_token_ids_json)` length 2. `radiant_token_index` picks Radiant (Blue) vs Dire (Red), same as Dota `market_seconds.py`.

Load window per map: `[spawn_us - 61s, max(state_wall_us) + 25s + 300s]` via `load_token_book`. Either book `None` → map `missing_books`.

### Prior (map-level)

Window `[spawn_us - 61s, spawn_us)` — **exclusive** of the spawn snapshot.

Do **not** call `find_asof_quote` (5s age). One lookup at `target_us = spawn_us - 1`:

- Last two-sided quote on each token with `book_ts_us <= target_us`.
- Both `book_ts_us >= spawn_us - 61s` (no older fallback).
- `normalize_pair_mids(..., tolerance=PAIR_SUM_TOLERANCE)` → `blue_mid / (blue_mid + red_mid)` after orientation.

Any miss / one-sided / stale-vs-61s / pair-sum fail → drop **whole map** `missing_prior`. Constant on every row of the map.

### Current / target (row-level)

```
current_us = state_wall_us + 25 * US_PER_SECOND
target_us  = current_us + 300 * US_PER_SECOND
```

Reuse `lookup_market_p_after(radiant, dire, state_wall_us, 25)` and `lookup_market_p_after(..., 325)` (or 300 after current). That is existing Telonex as-of: last snapshot `<= t`, two-sided, age `<= 5s`, pair-sum `1 ± 0.05`. No 85 ms latency. No future reads.

Unusable current **or** target → drop **that row only**. Count in audit (`skipped_market_rows`).

### Label

Parquet has **no** `label` column. Trainer already does `signal_market_p_radiant_300s - market_p_radiant`. Both columns required and finite on every published row.

### Map vs row drops

**Whole map:** `no_livestats`, `no_spawn_frame`, `livestats_invariant_violation`, `missing_books`, `missing_prior`, `unresolved_market`, `zero_usable_rows` (grid+market left nothing).

**One row:** frame age > 2s; current/target gate fail.

## Split + publish (design §9.8–9.9, §11)

Split driver = `min(start_time)` of maps in the same `event_id` that have a spawn clock (dropped-for-market maps still contribute the driver if they spawned). Then:

- `event_start < VALIDATION_START_TIME` (1780563592, `2026-06-04T08:59:52Z`) → entire event **train**
- `event_start >= cutoff` → entire event **validation**

Never split two maps of one PM event. `production_training.parquet` = all accepted rows (train ∪ validation).

### Dataset schema

Exactly `list(DatasetRow.__annotations__)` in that order, no LoL-only columns:

`match_id`, `start_time`, `second`, `radiant_win`, `radiant_nw_adv`, `radiant_nw`, `dire_nw`, `radiant_xp_adv`, `deaths_radiant`, `deaths_dire`, `top1_nw_adv`, `radiant_top1_nw_ratio`, `dire_top1_nw_ratio`, `market_radiant_prior`, `market_p_radiant`, `signal_market_p_radiant_300s`

All three dataset files use this schema (not Dota’s wide `ValidationDatasetRow`).

After build, assert: columns match; `match_id == int(esports_game_id)` unique across production; per-map row count `<= 541`; `second` in `0..540`.

### `LolPrepareSplitRow`

`match_id`, `event_id`, `esports_game_id`, `game_number`, `start_time`, `event_start_time`, `split` (`train`|`validation`). One row per **accepted** map. No `backtest_book_gap_excluded`.

### `LolPrepareAuditRow`

One row per **linked** map: ids, `start_time` (null if no spawn), `split` (`train`|`validation`|`none`), `included`, `reason`, `invariant_rule` (null unless violation), `pause_count`, `pause_seconds`, `frame_count`, `grid_seconds` (seconds that passed the age gate), `dataset_rows`, `skipped_age_rows`, `skipped_market_rows`. Sort `(event_id, game_number, esports_game_id)`.

Print counts per reason plus invariant-drop count vs cap.

### Atomic replace

Build all five frames in memory. If the invariant cap trips or uniqueness fails, raise and leave the output dir untouched. Then `write_parquet_rows` each of the five (`.tmp` + `replace`). Empty accepted set still writes schema-only parquets + full audit (Stage 06 will fail on empty train; that is honest). Never write `game_states.parquet`.
