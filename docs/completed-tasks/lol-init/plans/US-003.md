## Download loop

**Input:** every row in `links.parquet` (accepted maps only). Missing/empty links file is fatal `RuntimeError`.

**Anchor rounding:** `t0 = loading_anchor_ts - (loading_anchor_ts % 10)`. Format `startingTime` as `YYYY-MM-DDTHH:MM:SS.000Z` via `datetime.fromtimestamp(t0, tz=UTC).strftime("%Y-%m-%dT%H:%M:%S.000Z")`. First request always includes `startingTime` (do not repeat Stage 03's no-param first window).

**Grid:** `T, T+10, T+20, ...` immediately. No sleep between successful windows.

**Per-map sequential loop** (one map = one executor job):

1. Resolve existing payloads (`read_existing_archive` below). Next `T` = `t0` if empty, else `floor_10(max rfc460Timestamp of last saved line that has frames) + 10`. If the last saved lines have empty `frames`, walk backward to the last line with stamps; if none, `T = t0`.
2. If skip-validation says done, return audit row without HTTP.
3. For each `T` while `T - t0 <= LOL_FETCH_MAX_WALL_SECONDS`:
   - `GET window/{id}?startingTime={format(T)}` through `fetch_window_at`.
   - 401/403: raise `RuntimeError` (existing `fetch_json` behavior). Worker must not catch this.
   - 404: stop this map, `reason=http_404`, `complete=False`, keep any lines already saved.
   - `EmptyHttpBody`: zero frames, **do not write a JSONL line**, advance `T += 10`. Continue (windows outside play, design §7.3). Not a parse error.
   - JSON body: `validate_window_body` (incompatible schema aborts the **run**, same as Stage 03). Append the **raw** object as one JSONL line. Empty `frames: []` is a valid line (pause / quiet slice).
   - After each saved line, rewrite `.partial` (full gzip of all lines so far) so a crash loses at most the in-flight request. Gzip append-members are unnecessary; one map is a few MB uncompressed.
   - Stop with `reason=complete`, `complete=True` when `max_game_second(all frames) >= 1200`.
4. If the loop ends because `T - t0 > 3600`:
   - zero saved lines → `complete=False`, `reason=empty_body`
   - else → `complete=True`, `reason=wall_time_limit` (safety stop; short games never hit second 1200; do not retry forever)
5. `RetryableHttpError` after tenacity exhausts: `complete=False`, `reason=retries_exhausted`, keep saved lines.
6. Validate `.partial` as gzip JSONL, then `partial.replace(target)`. Always promote on map stop (complete **or** error) so resume has a file.

**Game second (stop + `max_game_second` only):**

Frames live at `blueTeam.participants[]` / `redTeam.participants[]` (handoff sample), not `window.participants`. A frame has gold when any participant `totalGold > 0`.

```
spawn_wall     = first frame wall with gold
pause          = gap between consecutive post-spawn frames > LOL_PAUSE_MIN_GAP_SECONDS (5)
game_time      = frame_wall - spawn_wall - sum(pause durations fully ended before frame_wall)
max_game_second = floor(max game_time) or None if no spawn
```

Parse `rfc460Timestamp` with `datetime.fromisoformat(...Z → +00:00)` and use **float** unix seconds (do not use `parse_ts`; it truncates to int and would mis-handle 5.52s loading→spawn). Do not extract a shared clock module. Do not enforce Stage 05 invariants (500 gold, 10 players, monotonic gold).

Monkeypatch `LOL_FETCH_END_SECOND` / `LOL_FETCH_MAX_WALL_SECONDS` in tests that should not issue 120 real windows.

**Concurrency:** `ThreadPoolExecutor(max_workers=LOL_MAX_CONCURRENCY)` one future per map, `as_completed`. One shared `http_client()` (httpx.Client is thread-safe). 401/403: `future.result()` raises; `shutdown(wait=False, cancel_futures=True)` and re-raise. Do not write `download_audit.parquet` on auth abort (in-flight `.partial` files stay for later resume). Other map errors stay in the audit list; remaining futures finish.

**Exit code:** after all maps, write audit, print counts. `raise typer.Exit(1)` if any row has `complete=False`. `complete=True` with `wall_time_limit` is a finished job, exit 0.

**CLI:** `--links-path` (default `LOL_LINKS_PATH`), `--windows-dir` (default `LOL_WINDOWS_DIR`), `--audit-path` (default `LOL_DOWNLOAD_AUDIT_PATH`). No `--fetch` flag; this stage always downloads except validated skips.

## Raw archive format

Path: `data/lol/raw/lolesports/windows/<esportsGameId>.jsonl.gz`

- One line = one raw provider window object (`json.dumps` via `encode_json`), request order.
- No envelope, no frame flattening, no dedup (prepare does `rfc460Timestamp` dedup).
- Work file: `target.with_suffix(target.suffix + ".partial")` i.e. `*.jsonl.gz.partial`.
- Gzip: `gzip.GzipFile(filename="", mode="wb", mtime=0)` like Stage 03 `write_gzip_json`.

**Resume / skip protocol:**

1. Candidate files: if `.partial` exists and `archive_is_valid`, use it (crashed run). Else if target exists and valid, use it. Else start empty. Invalid gzip/JSON → ignore that file, do not skip.
2. `archive_is_valid(path, esports_game_id)`: gzip opens; every nonempty line is a JSON object; `validate_window_body` succeeds; `esportsGameId` matches.
3. **Skip HTTP** only when valid archive AND `max_game_second >= LOL_FETCH_END_SECOND`. Do not skip on previous `http_404` / `empty_body` / `retries_exhausted` (retry those). `wall_time_limit` skip: valid archive AND previous audit row for this id has `reason=wall_time_limit` and `complete=True`; if audit is missing, resume from last frame (may re-request the empty tail up to 3600 once, then write complete).
4. After successful `partial.replace(target)`, leftover `.partial` is gone (`Path.replace`).

`scripts/compare_collector_to_telonex.py` is the policy twin (skip after validate, write `.partial`, replace, fatal 401/403). Copy the policy, not the script.

## Retry / backoff / audit reasons

Reuse Stage 03 `fetch_json` (do not fork a second retry stack):

| Condition | Behavior | Map `reason` |
|---|---|---|
| `httpx.TransportError`, HTTP 429, HTTP 5xx | retry 5 attempts, exponential 1–30s | after exhaust: `retries_exhausted`, continue other maps |
| HTTP 401 / 403 | `RuntimeError`, abort run, no audit parquet | — |
| HTTP 404 | no retry, stop this map | `http_404` |
| HTTP 200 empty body | `EmptyHttpBody`, 0 frames, continue grid | `empty_body` only if the map ends with **zero** saved lines |
| HTTP 200 JSON, empty `frames` | save line, continue | — |
| Incompatible JSON / missing `esportsGameId`/`frames` | `RuntimeError`, abort run | — |
| Other 4xx | existing `fetch_json` `RuntimeError`, abort run | — |
| `max_game_second >= 1200` | stop map | `complete` |
| query wall `T - t0 > 3600` with ≥1 line | stop map | `wall_time_limit` |

Retry tests must `monkeypatch.setattr("time.sleep", lambda _: None)` so tenacity does not wait.

## `download_audit.parquet` schema

TypedDict `LolDownloadAuditRow`. One row per links row. Sort `esports_game_id`. Integer columns pandas `Int64`. Write via `write_parquet_rows`. Unique `esports_game_id` is fatal if duplicated.

| column | type | meaning |
|---|---|---|
| `esports_game_id` | `str` | map id, filename stem |
| `event_id` | `str` | from the link |
| `esports_match_id` | `str` | from the link |
| `game_number` | `int` | from the link |
| `window_response_count` | `int` | JSONL lines saved (empty HTTP bodies do not count) |
| `unique_frame_count` | `int` | unique `rfc460Timestamp` across saved lines |
| `max_game_second` | `int \| None` | floor of pause-aware game time; null if no spawn frame |
| `complete` | `bool` | True iff `reason` is `complete` or `wall_time_limit` |
| `reason` | `str` | exactly one of the five reason constants |

Print totals: `complete`, `wall_time_limit`, `http_404`, `empty_body`, `retries_exhausted` via `print_count`.

| Incomplete exit | two maps, one 404 → `typer.Exit` code 1 and audit contains both rows |
