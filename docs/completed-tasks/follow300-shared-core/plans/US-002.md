# US-002: Build the dependency-free Follow300 core

## Goal

Add `src/strategy/` in `esports-trader` (`ladder-experiment`): types, one Follow300 policy, signals, lifecycle, quoting, single-event engine. Extraction semantics only. Tests and typecheck pass. Backtest and live stay unwired.

## In

- New package `src/strategy/{types,policy,signals,lifecycle,quoting,engine}.py` plus `__init__.py`.
- Frozen dataclasses only. No `dict[str, Any]`. No anonymous tuples. All function args required.
- Extraction SELL table: a new BUY fill restarts 10s settle; working SELL is cancelled on the **next requote**. No 1s SELL min-life. No MATCHED-unconfirmed hold.
- Cadence fields exist; extraction uses `fallback_timer_s=1.0`. Do not apply live `debounce_ms=100` / `quoter_tick_s=2.0`.
- Ownership by `episode_id` from submit time. A fill credits that order's episode, not "current rung by index". Do **not** add the US-008 gate (block new BUY until unresolved late-fill ownership is reconciled). The four US-001 maps are not that scenario.
- Dust (`position_qty < min_order_size`) is a real position: episode stays open; no SELL; do not treat flat.
- Cancel request does not free a rung or BUY reserve. Confirm, reject, or racing fill does.
- Submit/cancel **timeout is unknown**, not reject: rung and reserve stay occupied.
- `level_usdc` is a required policy field. Core has no Dota/LoL and no live/backtest size constants (`$100/$65/$20` live in adapters later).

## Out

- Do not edit `DotaMakerStrategy`, `maker_orders.py`, trader adapters, `config/trading.toml`, `docs/extraction-oracle.md`, goldens, or `extraction_identity.py`.
- Do not edit `../poly-maker`.
- Do not run the four-map replays or US-001 compact harness as this step's proof.
- Do not apply US-008 labeled changes (late-fill table, SELL min-life/MATCHED, 100ms/2s).
- Do not persist snapshots (US-006) or shared-wallet multi-game (US-007).

## Quoting (`src/strategy/quoting.py`)

Pure: state + policy → desired targets → diff against `state.orders` → `Plan`. Occupy rungs / append pending orders in the returned state (caller is engine).

| New function | Extract from |
| --- | --- |
| `choose_targets(*, state, policy) -> tuple[PlaceOrder, ...]` (targets without ids yet: use a frozen `QuoteTarget` in this module: `token_index, side, price, quantity, level_index`) | `_choose_targets` `:822`, `_choose_buy_targets` `:967`, `_open_buy_targets_for_token` `:910`, `_pick_episode_token` `:858`, `_choose_sell_target` `:1003`, `_buy_is_closed` `:895`, `_rung_price` `:170` |
| `reconcile(*, state, policy, targets) -> tuple[StrategyState, Plan]` | `_unmatched_live_and_missing_targets` `:1048`, `_reconcile_targets` `:1070`, `_live_matches` `:1086`, `_reattach_level` `:1283`, `_submit_target` `:1100` |

Rules to copy exactly:

1. One latched token per episode (`episode_token_index` or `position.token_index` or max-edge pick; lower `token_index` wins a tie — `:887-892`).
2. Up to `level_count` open BUY rungs, step `step_ticks * tick_size` below join bid. Skip `done` rungs. Do not refill a done rung.
3. Before first BUY fill: rung prices frozen from last latch rebuild (`follow_book=False` → keep `rung.price`). After first fill: unfinished rungs follow the book (`follow_book=True`). Fair stays the model latch.
4. BUY keep/move/replace is **price** (and token/side), not leftover size (`live_matches_target` `:176-187`). Same price → `KeepOrder` (or `MoveOrder` if `level_index` changed). Price moved → cancel old + `PlaceOrder` at **full** `level_usdc` (`_buy_quantity` `:167-168` / `buy_share_quantity`). Partial fill + same price → keep, do not resize.
5. SELL keep also requires remaining qty == `share_floor(position.qty)` (`_live_matches` `:1095-1098`).
6. Short budget: if the rung is not already occupied and `available_usdc < price * qty`, **skip the whole rung**. Do not shrink `level_usdc`. Block reason `no_cash` only when every candidate rung was cash-blocked (see `_cash_blocked_a_buy` `:1461`).
7. BUY and one SELL may rest together. Open position does not block BUY (`POSITION_OPEN` is live-only; do not port it).
8. While `is_settling`: no SELL target. Next Wake therefore unmatched-cancels a working SELL (`reprice`). That is the extraction SELL table.
9. `sell_only` or `reduce_only` or not `allow_buy` or cutoff (`game_second >= buy_cutoff_second`) or `winding_down` or token mismatch → no new BUY. Cutoff cancels resting BUY (`_on_buy_cutoff` `:465`, `_evaluate` `:542-543`).
10. HALT / paused / stale book / unusable exit fair / game_ended → cancel all (or all BUY for entry-stale with position still open — `_latch_for_quote` `:626-640`).
11. Skip reprice-cancel when `inventory_is_dust`.
12. Do not place BUY on an occupied rung (includes canceling/unknown). Do not place a second SELL.

Latch rebuild on requote (not on Book/Signal store): port `_sync_grid_latch` `:747` / `_rebuild_latch` `:773` / `_latch_for_quote` `:605` using **stored** signal + books + `FreshnessLimits`. New model tick = `signal.received_ns` newer than `latch.fair_ts_ns`. Anchor fail carries previous fair (`:776-790`).

Target quantity: BUY `buy_share_quantity(base_size_usdc=policy.level_usdc, price=price)`; SELL `share_floor(position.qty)` if `qty >= limits.min_order_size`.

## Engine (`src/strategy/engine.py`)

```python
def step(*, state: StrategyState, policy: Follow300Policy, event: InboundEvent) -> EngineOutput: ...
```

1. Apply event → new state (`lifecycle` + store books/signal/clock/permissions/budget).
2. If event is `Wake`, `CancelAck`, or `Recovery`: run latch + `choose_targets` + `reconcile`. Else plan is empty.
3. Occupying a `PlaceOrder` happens inside `reconcile` (pending order, rung `live_id`, reserve conceptually via occupancy). Adapter success is not assumed; `OrderRejected` / timeouts come later.
4. `next_wake_ns = event.now_ns + int(policy.fallback_timer_s * 1e9)`. Do not read `debounce_ms` this step.
5. HALT: cancel all, empty places, `block_reason="halt"`.

`src/strategy/__init__.py` exports `step`, `extraction_policy`, `Follow300Policy`, `EngineOutput`, and the event/plan types tests need. Nothing else.

Keep functions small enough that ruff C901 stays quiet (split the way `strategy.py` already is). Do not move `DotaMakerStrategy` wholesale.

### `tests/test_strategy_core.py`

Helper: `extraction_policy(level_usdc=100.0)`, two-sided books at a chosen bid/ask, a `RawDeltaSignal`, `step` through `BookUpdate` + `SignalUpdate` + `Wake`. `now_ns` in nanoseconds. `FreshnessLimits(book_stale_s=5, entry_stale_s=16, exit_stale_s=45)`, `MarketLimits(min_order_size=5, tick_size=0.01, pair_sum_tolerance=0.05, radiant_token_index=0)`.

Required cases (both polarities = token 0 and token 1 / +delta and −delta):

1. **Filter boundaries, both polarities**
   - `|predicted_delta| < 0.01` → no BUY places, `block_reason="min_delta"`. `== 0.01` admits.
   - `nw_delta_30` NaN → `missing_nw`; `>= 350` → `nw_velocity`; `349.9` admits.
   - join bid `< 0.35` → `min_price`; `== 0.35` admits if edge ok.
   - spread `>= 8` ticks → `wide_spread`; `7` admits.
   - +delta picks the +edge token; −delta picks the other; equal edge prefers `token_index` 0.
2. **Duplicate fill** — place, accept, `Fill(fill_id="f1")`, same `fill_id` again: position/rung unchanged.
3. **Cancel-then-fill race** — `Wake` emits cancel (e.g. cutoff or reprice); before `CancelAck`, `Fill` on that `order_id` credits position; cancel request did not free the rung; after `CancelAck`, occupancy clears. Port of compact `fill_cancel_race` semantics without the Nautilus harness.
4. **Keep vs move vs replace**
   - Keep: second `Wake`, same bid → `keep` contains the live id, no cancel/place.
   - Move: top rung fills; book join moves so a resting lower order's **price** still matches a different `level_index` → `MoveOrder`, `awaiting_cancel` false, no venue cancel.
   - Replace: bid moves one tick, unmatched → cancel + new `PlaceOrder` with **full** `level_usdc` qty even after a partial fill on that rung.
5. **Cutoff during submit** — `PlaceOrder` still `pending`; `ClockUpdate`/`Wake` at `game_second=540` → no new BUY, cancel the pending id, rung occupied until `CancelAck`.
6. **Cancel timeout** — after canceling, `CancelTimeout` leaves status `unknown`, rung still occupied, no second place on that index.
7. **Recovery event shape** — `Recovery(restored_buy_ids=("c0",), verified_qty=10, verified_token_index=0)` on a state that has that BUY: `sell_only=True`, plan cancels `c0`, later `Wake` has no BUY places.

Add the smallest extras that lock US-002 rules (same file, not a framework):

- `SubmitTimeout` does not drop the pending order.
- Settling: BUY fill then `Wake` inside 10s → SELL cancelled if it was live; `Wake` after 10s may place SELL.
- Dust: BUY partial such that `qty < 5` → no SELL place, episode not idle.
- Short budget: `available_usdc` just under one rung notional → that rung omitted, other affordable rungs unchanged, sizes still full `level_usdc`.
