### Пункт 2. GRID `NetWorth` и livestats `totalGold` — разные величины

Из сырого GRID-фрейма: `NetWorth = Money + LoadoutValue`. Проверено на
игроках: 365 + 1700 = 2065, 1381 + 2150 = 3531. Это текущее нерастраченное
золото плюс стоимость предметов.

livestats `totalGold` — всё заработанное с начала карты. Разница это варды,
зелья и потери на перепродаже.

Отношение GRID к livestats на 1566 парах при сдвиге +7:

| Сторона | p10 | медиана | p90 |
|---|---|---|---|
| blue | 0.947 | **0.957** | 0.976 |
| red | 0.925 | **0.949** | 0.958 |

GRID ниже на 4–5%, стороны смещены по-разному. Это даёт смещение главной
фичи:

| Величина | p10 | медиана | p90 |
|---|---|---|---|
| `nw_adv` GRID минус livestats | −15 | **+133** | +382 |
| `nw_adv` сам сигнал livestats | −1033 | −145 | +446 |

Знак `nw_adv` расходится на 15% сэмплов (242 из 1566).

`xp_adv` на правильном сдвиге: медиана расхождения 0, p10/p90 равны −480 и
+480 при собственном размахе сигнала −980..+1280. Знак расходится на 13%.
Цифра 680 для `xp_adv` была на неверном сдвиге +22.

Остальные фичи:

| Фича | Расхождение |
|---|---|
| `deaths_blue`, `deaths_red` | совпадают точно |
| `top1_ratio_over_rest` | 1.8% |
| `top1_ratio_over_total` | 1.3% |
| `xp_adv` | медиана 0, p10/p90 −480/+480, знак 13% |

## Побочные находки

Формулы top1 расходятся. Модель LoL обучена на `top1 / сумма`
(`lol/livestats_frames.py:397`). Live-путь Dota считает
`top1 / (сумма − top1)` (`shared/utils/top_players.py`). На спавне 0.20
против 0.25. Правка — стадия 5 плана.

GRID не шлёт `increaseLevel`, пока на карте не случился первый level-up.
`_player_from_row` тогда ставит всем уровень 1. Это верно до первого
level-up. У GRID есть сырой `ExperiencePoints`; модель обучена на лестнице
уровней.

Разрежённость GRID. На CBLOL 167 сэмплов за 715 секунд, один раз в 4.3
секунды. livestats даёт около 3 Гц. Часть разброса — разрежённость, но
медианное смещение +133 ею не объясняется: симметричный шум дал бы медиану
около нуля.

## Реконструкция GRID-золота из истории lolesports

GRID подтверждает расхождение [в FAQ](https://grid.helpjuice.com/client-help/why-is-networth-on-grids-api-different-from-the-net-worth-total-gold-value-on-the-broadcast-lol):
их `netWorth = money + loadoutValue`, Riot `totalGold = money + loadoutValue +
стоимость потреблённых предметов`. «Работаем над исправлением, ETA нет».

```
nw_rec(t) = totalGold(t) − consumed(t)
```

`consumed` считается по эндпоинту `details`: он работает и для прошедших
игр, отдаёт те же кадры с `items` и `totalGoldEarned`, равным `totalGold`
окна. Падение количества предмета с флагом `consumed` из Data Dragon между
соседними кадрами × его цена — потреблённое золото.

Проверено на записи CBLOL против настоящего GRID NetWorth, сдвиг +7, 1235
пар (`scripts/reconstruct_lol_networth.py`):

| Величина | сырое totalGold | реконструкция |
|---|---|---|
| blue: медиана ratio к GRID | 1.046 | **1.002** |
| red: медиана ratio к GRID | 1.054 | **0.997** |
| blue/red: медиана \|x − GRID\| | 545 / 715 | **44 / 69** |
| nw_adv: медиана gap | −135 | **+17** |
| nw_adv: перевороты знака | 16.0% | **5.8%** |

Систематики по времени в остатке нет (медианы 2-минутных бакетов ±100).
Оставшиеся 5.8% переворотов сидят около нулевого преимущества — шум
разрежённости GRID. Асимметрия сторон: red потратил на расходники 1275
золота против 850 у blue, разница 425 — тот же порядок, что asymmetry
сырых гэпов (715 против 545).

Оговорки:

- Одна карта. На новой двойной записи прогонять
  `reconstruct_lol_networth.py` — скрипт сам достаёт и кэширует `details`
  и таблицу цен.
- Цены из последнего патча Data Dragon. Для рефетча истории брать патч из
  `gameMetadata.patchVersion` в каждом window-архиве.
- Продажа предметов неотличима от потребления; в первые 10 минут про-игры
  её почти нет. Эликсиры — после 20-й минуты, вне окна обучения 0..540 с.
- Точного равенства с GRID не будет: карманное золото lolesports не
  отдаёт. Остаток 0.2–0.5% без систематики.

Переобучение на этой реконструкции идёт отдельно, до стадий live-плана.
Исторический GRID отдаёт только конечный снапшот серии, прогрессии золота
нет. Торговать по livestats нельзя: 60 секунд отставания.
