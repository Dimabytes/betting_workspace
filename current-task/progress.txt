## 2026-08-14 - US-008 review fixes round 2 (Luna re-review P1: fd2 race)
- Reproduced the two-thread interleave: A enters/devnull, B saves devnull, A
  exits restoring real stderr while B's native write runs, B's exit leaves fd 2
  on devnull (later stderr lost) — the unlocked _SilencedStderr was racy.
- `_SilencedStderr` now holds a process-wide `threading.RLock`
  (_STDERR_SILENCE_LOCK) from the redirect through the wrapped native call to
  the restore: concurrent windows serialize, nested windows on one thread
  re-enter safely, and no interleave can save another thread's devnull fd.
- __enter__/__exit__ are exception-safe: a failing devnull open closes the
  dup'd fd, a failing redirect dup2 closes both descriptors, both release the
  lock and leave fd 2 untouched; __exit__ restores fd 2, closes both fds, and
  releases the lock in a finally that runs on body errors too. No
  BaseException is swallowed (cleanup-and-reraise only).

  the window while B enters; per-thread release events force A's exit before
  B's native write; asserts neither path reaches captured stderr and an
  AFTER-marker written post-join is captured, proving fd 2 restored); body
  exception + nested windows restore; enter open-failure and enter dup2-failure
  cleanup (fd-count via /proc/self/fd, lock released — a second window works).

  exact PATH-LEAK interleave; removing the open-failure fd cleanup makes the
