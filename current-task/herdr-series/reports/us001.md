### 1. `src/strategy/series_link.py` — pure math, no IO except `load_series_c`

```
Q0_GRID: tuple[float, ...]          # round(0.02 + 0.01*i, 2), i in 0..96  → 0.02..0.98
Q0_MAX_FIT_ERROR = 0.03
HORN_PRICE_MIN = 0.05               # exclusive bounds on horn map/series price
HORN_PRICE_MAX = 0.95
MIN_SERIES_SLOPE = 0.05
SERIES_C_BUCKET_EDGES = (120, 240, 360, 480)   # game-second upper edges
SERIES_C_FILENAME = "series_c.json"

SeriesBranch = Literal["line", "line_x_c"]
HornFitStatus = Literal["ok", "price_bounds", "fit_error", "flat_slope"]

@dataclass(frozen=True)
class HornQ0Fit:
    status: HornFitStatus
    q0: float | None          # set only on "ok"
    slope: float | None       # B at q0, set only on "ok"
    fit_error: float | None   # argmin residual, set on "ok" and "fit_error"

def series_wins_target(best_of: int) -> int:            # best_of // 2 + 1
def calculate_series_win(wins_a: int, wins_b: int, wins_needed: int, q: float) -> float
def calculate_series_slope(wins_a: int, wins_b: int, wins_needed: int, q0: float) -> float
def fit_horn_q0(*, map_p: float, series_p: float,
                wins_radiant: int, wins_dire: int, best_of: int) -> HornQ0Fit
def series_c_bucket(game_second: int) -> int            # 0..3, clamps outside [0,480)
def calculate_series_delta(*, slope_b: float, predicted_delta: float,
                           game_second: int, branch: SeriesBranch,
                           c: Sequence[float]) -> float
def pick_series_token_index(*, outcome_0: str, outcome_1: str,
                            radiant_name: str, dire_name: str,
                            aliases: Mapping[str, tuple[str, ...]]) -> int | None
def load_series_c(model_dir: Path) -> tuple[float, float, float, float]
```

Semantics:

- `calculate_series_win` = W recursion `W(a,b) = q·W(a+1,b) + (1−q)·W(a,b+1)`, bases
  `a==n → 1.0`, `b==n → 0.0`. No memo needed: n ≤ 3 gives ≤ ~64 calls; c-bucket math is per
  decision tick, cheap. (`likely` — trivially verified by control tests.)
- `calculate_series_slope(a,b,n,q0)` = `W(a+1,b;n,q0) − W(a,b+1;n,q0)`.
- `fit_horn_q0` order of refusal: `price_bounds` (either price outside open (0.05, 0.95)) →
  `fit_error` (argmin residual > 0.03 over `Q0_GRID`) → `flat_slope` (`B(q0) < 0.05`) → `ok`.
  Note `likely`: with both prices inside (0.05, 0.95), `flat_slope` is unreachable for real
  scores (small B co-occurs only with saturated S ≈ 0/1) — the guard is spec-mandated
  belt-and-suspenders; keep it.
  No Game N+1 q0 fallback and no mid-game q0 (feature.json): when the horn fit refuses, the
  map simply has no q0 — US-002 treats that as "no series trades", never as a cohort drop.
- `series_c_bucket(second)` = `min(3, max(0, second // 120))` — identical to research
  `bucket=sec//120`; buckets 0–120, 120–240, 240–360, 360–480 s, ≥480 clamps to 3.
- `calculate_series_delta`: `line` → `slope_b * predicted_delta`;
  `line_x_c` → `slope_b * c[series_c_bucket(game_second)] * predicted_delta`. Branch is a
  required argument — **no branch constant inside this module** (feature.json; `--series-branch`
  flag arrives in US-002).
- `pick_series_token_index`: `orient_outcomes(outcome_0, outcome_1, radiant_name, dire_name,
  aliases)` → `True→0`, `False→1`, `None→None`. This is the only allowed way to pick the series
  token: by the **name** of this map's radiant team, never by copying the map's token index
  (FR-2).
- `load_series_c`: `read_json(model_dir / SERIES_C_FILENAME)` (`shared/utils/json_io.py`),
  expect `{"c": [4 finite floats]}`; raise `ValueError` on missing key / wrong length /
  non-finite. Missing file surfaces as `FileNotFoundError` from `read_json`.


```
    """Series contract bound to one non-decider map; orientation + score resolved."""
```

`select_series_validation_matches` algorithm:

1. `coverage_map, map_eligible_ids = select_validation_matches(sources)` — reuse unchanged;
   copy its counters into `SeriesCoverage`, `map_eligible = len(map_eligible_ids)`.
2. Precompute `series_by_event: dict[str, UniverseMarket]` — only events with exactly one
   `series_winner` row are included.
3. For each map-eligible `match_id` (order preserved), call
   `resolve_series_market(sources.catalog[match_id], universe, series_by_event, gamma,
   scores)`; `SeriesMarket` → eligible + `match_ids`, a `SeriesGate` → bump its counter.

`resolve_series_market` gates, in order:

- `not_series_map`: `u_map = universe.get(row.condition_id.lower())` missing,
  `contract_kind != "map_winner"`, `best_of not in {3,5}`, or `game_number` None / outside
  `1..best_of-1` (BO3 ⇒ 1–2, BO5 ⇒ 1–4; the bound excludes BO2 map 1).
- `without_series_contract`: `ser = series_by_event.get(u_map.event_id)` misses (zero or
  multiple series rows on the event — multi doesn't occur today, verified).
- `without_series_score`: `row.spawn_at` (`datetime | None`, match_catalog.py:35) None or
  `scores.get(int(row.spawn_at.timestamp()))` misses. Score is **prior maps only** by
  construction in the loader.
- `orientation_failed`: `g_ser = gamma.get(ser.condition_id)` missing, `g_ser.outcome_names`
  None, `u_map.team_a`/`team_b` None, or `pick_series_token_index(
  outcome_0=g_ser.outcome_names[0], outcome_1=g_ser.outcome_names[1],
  radiant_name=u_map.team_a if row.radiant_token_index == 0 else u_map.team_b,
  dire_name=u_map.team_b if row.radiant_token_index == 0 else u_map.team_a,
  aliases=TEAM_ALIASES)` returns None. The team_a ↔ token-0 convention is the same one
  `s02_link_opendota.py` used to derive `radiant_token_index`, so radiant's name is
  `team_a` iff index 0 — names, never the index, decide which series token is bought.
- `without_series_book`: `has_local_telonex_days(ser.token_ids,
  calculate_availability_window(map_load_at=row.anchor_at, game_ended_at=row.ended_at),
  RAW_TELONEX_POLYMARKET_DIR)` False — same channels as the map gate since the engine
  replays book + onchain_fills. Tests monkeypatch
  `series_inputs.RAW_TELONEX_POLYMARKET_DIR` like existing selection tests do for
  `backtest.selection` (`tests/test_backtest_validation.py`).
- `ok`: build `SeriesMarket` (slug/closed_at/seconds_delay from `g_ser`, contract fields
  from `ser`, score from the grid lookup).

Callers (US-002) load the three mappings once: `load_dota_universe()`,
`index_gamma_markets(POLYMARKET_UNIVERSE_EVENTS_DIR)`, `load_series_game_scores(
GRID_SERIES_STATE_DIR)`. The `--since-match` cohort can reuse `resolve_series_market` over
`select_dota_since_match_ids` output (selection.py:143) — same per-row resolver, no fork.

`find_horn_quotes`: `horn_us = int(context.horn_at.timestamp() * US_PER_SECOND)`; the caller
loads both books via `load_token_book` covering at least `horn−35 s .. horn+35 s` so the
whole ±30 s window is populated (the research loader used a 60 s pre-load). For `k` in 0..30
try `−k` then `+k` (the 0 offset once; equal-|offset| ties prefer the earlier second — same
as the research `argmin(|sec|)` over ascending seconds). At each candidate instant
`find_asof_quote(book, horn_us + off*US_PER_SECOND)` must return `status == "ok"` (two-sided,
≤5 s old — the built-in gate, telonex_book.py:210) and
`spread_ticks(quote.bid, quote.ask) <= 5` (`shared/utils/trading.py:40`) on **both** books.
First passing second wins; `None` if none pass. Mids are single-token mids (no pair
normalization — the research signal used the radiant token's mid directly): map token =
`context.token_ids[context.radiant_token_index]`, series token =
`series_market.token_ids[series_market.radiant_token_index]` (caller resolves which token's
book to hand in; this function just takes two books).

## Edge cases already decided

- Multi-`series_winner` events don't exist in today's universe (verified count), but the
  selection still guards: `series_by_event` keeps only exactly-one events.
- Map book days are still required (map mid feeds q0 at the horn and the model's
  `market_p_radiant`) — they come free via `select_validation_matches`.
- Series book window = the map's availability window. US-003 widens the replay window to
  game_end+15 min and must widen this check the same way (`likely` a one-day-boundary nit).
- `q0` is fit at run time from replayed books, not at selection time; a refused fit is **not**
  an exclusion — the map stays in the cohort and simply places no series trades (US-002).
