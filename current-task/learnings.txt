# Learnings for later live-source-picker stories

- `LiveFeed` / `FeedEvent` / `GameSnapshot` / `MatchPhase` live in `dota_2_model/src/live_paper/live_feed.py`. Consumers must not read Steam `game_state` or `event.payload`.
- Each feed owns its raw archive. `SteamLiveFeed` writes `state.jsonl` then yields. `GridLiveFeed.ticks()` writes every raw socket text to `grid_state.jsonl` before `read_frame`. MatchWorker has no `StateWriter`.
- `GridLiveFeed(series_id, map_number, sides, match_id)` — all required. `read_frame(raw, now)` is still the parse test seam; `pinned_board()` is the finished-map `won` read for finalize.
- `MatchWorker(host, discovered, model, mode, feed, feed_timeout_seconds)` — all required. Timeout goes to `FreshnessWatchdog`. Steam uses `FEED_STALE_SECONDS` (3.0); GRID uses `GRID_FEED_STALE_SECONDS` (12.0), already in `strategy.py`.
- `WalletHost._launch` is the single seam US-005 replaces with the picker: it currently always builds `SteamLiveFeed` + 3s, and returns without launching when `server_steam_id` is None.
- match.json is schema 2 only. `write_match_start` / resume refuse v1. `match_has_final` requires exact-int `schema_version == 2` before reading `final`. `steam_delay_s` is on the document and rebuilt from it; it stays `compare=False` so a later discovery delay cannot rebind.
- GRID `TeamSide.won` is true on the live recorded fixture for Dire; winner is taken only when that map's `status == finished`.
- Parse discovery `stream_delay_s` with a local non-raising reader — `require_nullable_int` would drop the whole GetLiveLeagueGames row.
- Horn is `FeedEvent.horn_unix_seconds` (non-nullable). Trust is the phase (`HORN_CLOCK_PHASES`), same as `is_horn_clock_state` used to be. Archive readers in `match_meta.summarize_archive` / `_first_trusted_horn_iso` still read raw Steam `state.jsonl`.
- Steam adapter maps 4→`pre_horn`, 5→`in_progress`, 6→`finished`, 2/3/8→`pre_match`. State 7 still ends the HTTP follow with no event.
- `steam_live_feed.py` is a separate module so `steam_feed` does not import `state_writer` (cycle: state_writer → steam_feed).
- GRID parse lives in `shared.utils.grid_widgets`. `GridLiveFeed` is `src/live_paper/grid_feed.py`. Tests are the only constructor until US-005. `read_frame(raw, now)` covers every parse rule without a socket.
- `score_team_name` observed names must already be `normalize_team_name`'d (discovery does this). Passing raw GRID "Team Lynx" fails the side gate.
- `same_table_content` compares `game_number` + `players` only. Including `feed_delay` would re-arm the 12s timeout on a delay wobble during a pause.
- GRID terminal is pinned-map `status == finished`, not series status. Horn is `occurredAt` epoch − raw `currentSeconds`, not the extrapolated clock.
- Recorded widget payloads live in `tests/grid_widget_fixtures.py` (series 2995964). Import them; do not copy.
