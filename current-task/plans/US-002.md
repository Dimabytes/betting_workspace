## Design: a series run is a market swap, not a new pipeline

The replay loop (`run.py`) treats `MarketContext` + `MatchSignals` as opaque. A
series run keeps the *map* cadence/feed/kill-gates and swaps:

1. `context_by_match[match_id]` → a series `MarketContext` (series
   `condition_id/slug/token_ids/radiant_token_index/seconds_delay/
   market_closed_at`, map's `match_id/event_id/horn_at/game_ended_at/replay_start/
   replay_end`, `clock_end = game_ended_at + SETTLEMENT_BUFFER`).
2. `MatchSignals.predicted_deltas` → `ΔŜ` per branch;
   `MatchSignals.dataset_market_ps` → as-of series mids (≤ 5 s) — the
   `anchor_p` the strategy will see. `feed_timestamps_ns`, `kill_gates`,
   `deaths_*`, `observed_clock` unchanged.
3. Postprocess pricing: `mids` → series mids; settlement valuation → terminal
   bids (mark, not outcome).

Everything else — batching, `run_batch`, `build_kernels`, telemetry, results —
is unchanged.

### 1. `src/backtest/series_run.py` — series assembly for `run.py`

Owns every series-specific piece so `run.py` only parses flags and calls it.
No imports from `run.py` (it is imported *by* `run.py` — one direction only).

Types:

```python
@dataclass(frozen=True)
class SeriesInputs:        # loaded once per process
    universe: Mapping[str, UniverseMarket]
    series_by_event: Mapping[str, UniverseMarket]
    gamma: Mapping[str, GammaMarket]
    scores: Mapping[int, SeriesGameScore]

@dataclass(frozen=True)
class SeriesCohort:
    markets: dict[int, SeriesMarket]          # keyed by map match_id
    drops: dict[int, SeriesGate]              # match_id → gate (non-validation modes)
    coverage: SeriesCoverage | None           # validation runs only
    refused: dict[int, str]                   # match_id → q0 refusal status (post-fit)

@dataclass(frozen=True)
class SeriesLegBooks:
    radiant: TokenBook    # series leg at market.radiant_token_index
    dire: TokenBook       # series leg at 1 - radiant_token_index

@dataclass(frozen=True)
class SeriesLookups:
    """What a series run threads through the generic pipeline."""
    context_by_match: dict[int, MarketContext]   # series contexts
    series_mids: dict[int, MidSeries]            # postprocess + anchors
    terminal_marks: dict[int, TerminalBids]      # per-token bid at clock_end
    gate_drops: dict[int, SeriesGate]
```

Functions (all arguments required, verbs, no `dict[str, Any]`):

- `load_dota_series_inputs() -> SeriesInputs` — `load_dota_universe()`,
  `index_gamma_markets(POLYMARKET_UNIVERSE_EVENTS_DIR)`,
  `load_series_game_scores(GRID_SERIES_STATE_DIR)`, and the `series_by_event`
  index (`{event_id: row}` keeping only events with exactly one
  `series_winner` row — the same 3-line comprehension currently inside
  `select_series_validation_matches`; move it into a shared
  `index_series_markets_by_event(universe)` helper in `series_inputs.py` and call
  it from both places).
- `resolve_dota_series_cohort(selection: DotaSelection, inputs: SeriesInputs)
  -> SeriesCohort`:
  - `--validation` mode (`selection.coverage is not None`): call
    `select_series_validation_matches(selection.sources, universe, gamma,
    scores)` once — it returns the full-cohort `SeriesCoverage` and the resolved
    `markets` map; the run cohort is `markets` restricted to
    `selection.selected_ids` (a `--limit` prefix is still covered: drops are
    counted over the whole map-eligible cohort, identical to how map runs report
    `coverage` for the full funnel under `--limit`).
  - `--match-id`/`--match-ids`/`--since-match` mode (`coverage is None`):
    resolve each selected id with `resolve_series_market(catalog_row, universe,
    series_by_event, gamma, scores)`. A dropped id under explicit `--match-id`
    raises `ValueError(f"match {id}: {gate}")` — the user asked for that map.
  - `drops` only records gates on *selected* ids (for non-validation modes) —
    validation drops already live inside `coverage`.
- `build_series_context(map_context: MarketContext, market: SeriesMarket)
  -> MarketContext` — the field swap described above; `radiant_win =
  market.radiant_won_series` (new field, see `series_inputs` changes);
  `clock_end = map_context.game_ended_at + SETTLEMENT_BUFFER` — never
  `max(..., market_closed_at)`.
- `load_series_books(markets, context_by_match, capture_root)
  -> dict[int, SeriesLegBooks]` — per match, `load_token_book` for both series
  legs over `[replay_start, replay_end]`; plus the map-radiant-token book over
  `[horn_at - 40 s, horn_at + 35 s]` (horn window ±30 s + 5 s as-of lookback) as
  a separate small `TokenBook` load used only by `find_horn_quotes`.
- `fit_series_q0(markets, books, horn_us_by_match) -> (dict[int, HornQ0Fit],
  dict[int, str])` — per match: `find_horn_quotes(map_book, series_radiant_book,
  horn_us)`; `None` → refusal `"no_horn_quotes"`; else `fit_horn_q0(
  wins_radiant, wins_dire, wins_needed, map_p=quotes.map_p,
  series_p=quotes.series_p)`; non-`"ok"` status → refusal keyed by status.
  `q0` is computed once per map here; the resulting `slope` is latched for the
  whole signal stream — no per-tick refit. (`likely` that keeping both books per
  match in memory is fine: 2 full-window series books + 1 sliver map book ≈ a
  few hundred KB per map; load lazily per batch only if profiling says otherwise
  — `ponytail:` note the ceiling.)
- `build_series_mids(books: Mapping[int, SeriesLegBooks], contexts)
  -> dict[int, MidSeries]` — per match, walk the union of both legs' snapshot
  timestamps inside `[replay_start, replay_end]`, as-of each leg (≤5 s),
  `normalize_pair_mids(radiant_mid=legs[rti].mid, dire_mid=legs[1-rti].mid,
  tolerance=PAIR_SUM_TOLERANCE)` → `market_p` radiant-oriented; skip pairs that
  fail freshness or normalization. This is the series mid cache.
- `write_series_cache(report_dir, series_mids, terminal_marks)` —
  `series_mids.parquet` (`match_id, ts_ns, market_p`) and
  `series_terminal.parquet` (`match_id, bid_0, bid_1`) in the run dir — the
  "кэш mid серии лежит в папке прогона" requirement; written before the replay
  loop, skipped/loaded on `--resume`, unioned across shard dirs by
  `--merge-shards`.
- `build_terminal_marks(books, contexts) -> dict[int, TerminalBids]` — per match
  `find_asof_quote` each series leg at `clock_end`; `bid` of each leg (ask side
  unused for valuation — a held token exits at its own bid); missing/stale →
  fall back to that leg's last mid inside the window; never fabricate `0`.
  `TerminalBids` is a small frozen dataclass `{bid_0: float, bid_1: float}` put
  in `src/backtest/marks.py` next to `settlement_value_for_token`.
- `build_decision_seconds(feed_source, signal_rows, plans)
  -> dict[int, dict[int, int]]` — decision `ts_ns → game_second`:
  - grid-v1 Dota: `{int(state_ts_us) * NS_PER_US: int(second)}` over the match's
    signal rows; duplicate `state_ts_us` → raise (data bug).
  - archive `schedule` Dota: `{tick.received_ns: tick.game_second}` from
    `plan.binding.schedule.ticks`.
  LoL (US-003) will need `ts - LOL_SOURCE_LAG_SECONDS·1e9` first — named in a
  comment, not built.
- `to_series_signals(map_signals, fits, books, second_of_ts, branch, c)
  -> SeriesSignalsOut` where `SeriesSignalsOut = {signals: dict[int,
  MatchSignals], dropped_decisions: dict[int, int]}`:
  per match, per decision index `i`:
  - `second = second_of_ts[match][ts_i]`
  - `ΔŜ = calculate_series_delta(slope_b=fit.slope, predicted_delta=δ_i,
    game_second=second, branch=branch, c=c)`
  - anchor = `normalize_pair_mids` of the two as-of series quotes at `ts_i`;
    missing/stale/one-sided pair → drop decision `i` from all parallel arrays
    (`timestamps_ns/predicted_deltas/dataset_market_ps/deaths_radiant/
    deaths_dire`) and count it in `dropped_decisions`.
  This is the complete series `RawDeltaSignal` contract:
  `predicted_delta = ΔŜ`, `anchor_p =` as-of series mid ≤ 5 s, both
  radiant-oriented for the strategy's `radiant_token_index`.
- `series_summary_block(cohort, results, telemetry, clean_ids)
  -> dict[str, object]` — the `summary.json["series"]` object:
  `{"branch": ..., "cohort": {gate: count} incl. "without_series_book",
  "q0_refused": n, "q0_refused_by_reason": {...},
  "anchor_dropped_decisions": n,
  "blocks": {"min_delta": n, "wide_spread": n, "anchor": n}}` where blocks are
  summed from `kind_counts` rows with `kind == "no_quote"`, `reason` in the set,
  `match_id ∈ clean_ids` — same counting rule as `gate_seconds`, different
  source (telemetry already aggregates per reason; `wide_spread` is folded into
  `GateSeconds.other` today so the gate struct cannot provide it).

## Behavior contract this step must land

1. **q0 once per map**: `fit_horn_q0` runs exactly once per selected map at
   `resolve`-time (before the replay loop), on the `find_horn_quotes` pair; the
   fitted `slope` is latched — no per-tick refit, no Game N+1 fallback (that
   fallback lives in the live design doc, not in this step — a missed horn fit
   means the map does not trade).
2. **Refusal ≠ gate**: series gates (`not_series_map`, `without_series_contract`,
   `without_series_score`, `orientation_failed`, `without_series_book`) drop the
   map at selection and live in coverage/cohort counts; `q0` refusals
   (`price_bounds`, `fit_error`, `flat_slope`, `no_horn_quotes`) produce a
   `terminated_early` result row with `stop_reason = q0_*` — excluded from
   `completed`, visible in `summary.series.q0_refused*`.
3. **Signal fields**: series `RawDeltaSignal` is exactly `{predicted_delta = ΔŜ,
   anchor_p = as-of series mid ≤ 5 s}`; `fair_radiant =
   clip(book_p + delta)` unchanged; the model keeps seeing map rows and the map
   mid feature — `to_series_signals` never touches `feature_rows`.
4. **Ladder**: policy is `resolve_run_policies` unchanged →
   `level_usdc = 100.0`, `BUY_LEVEL_COUNT = 3`, `step_ticks = 1` — same $100 / 3
   steps as the LIVE map catalog.
5. **Summary counters**: `summary.json["series"]["without_series_book"]` (cohort
   gate count) and `["blocks"]{min_delta, wide_spread, anchor}` (no_quote reason
   counts over clean matches) must be present for every `--market series` run.
6. **Window**: replay horn → `game_ended_at + 1 min`; leftover inventory marked at
   the window-end **best bid** per token (`TerminalBids`); no outcome settlement
   anywhere in a series run (`settlement_applied = False` is expected).
7. **LoL selection**: same-event single included `match_winner`; prior-game score
   from `links.parquet` (`game_number <` current, winner by
   `resolved_outcome_index == radiant_token_index`); per-map blue-name
   orientation through `pick_series_token_index` + `LOL_TEAM_ALIASES`; duplicate
   enabled `match_winner` → raise; all of it exercised by tests only — the LoL
   *runner* is US-003.
