### 3.4 Global contracts — abort before publish

Raise `RuntimeError` (nonzero). Leave `output-dir` untouched (no new parquets). These are **not** per-card audit reasons.

1. **Split:** `split.parquet` maps with `split=="validation"` are the card set. Duplicate `match_id` → abort. Any `event_id` with both train and validation → abort (Stage 05 already forbids this; re-check).
2. **Features:** research `model.json` `features` must equal `FEATURE_COLUMNS` (ordered). Production too.
3. **Source lag:** read `source_lag_seconds` from research `model.json`. Production `model.json` must exist and have the **same** int. That int must equal `LOL_SOURCE_LAG_SECONDS` (25), because `validation.parquet` was joined with 25. Mismatch → abort. Missing either `model.json` → abort. Do not recompute signals under a different lag.
4. **Orientation / outcome:** for each validation `match_id`, `radiant_win` in `validation.parquet` is constant and equals `resolved_outcome_index == radiant_token_index` from `links.parquet`. Mixed or disagreeing values → abort.
5. **Rows 0..540:** after rebuilding labeled rows with `join_market_rows` on the 0..540 grid slice, they must equal `validation.parquet` for that `match_id` on every `DatasetRow` column (same seconds, same values). Extra Stage 07 columns (`event_id`, `state_ts_us`) are not in that comparison. Any mismatch → abort (dataset/livestats contract is broken; do not publish a "close enough" cache).
6. **Duplicate published `match_id`** in the card set → abort.

Per-card failures (missing trades, missing cutoff, …) go in audit. Eligible cards still publish. **Exit 1 only when `eligible` count is 0** after a successful publish. If there are no validation maps in split, that is also zero eligible → publish empty signals/market + audit (or abort if split file empty/missing — missing split is a global input error, `RuntimeError`).

### 3.5 Per-card pipeline (validation maps only)

Process only `split=="validation"`. Join each `match_id` to `links.parquet` by `int(esports_game_id)`.

1. `prepare_map_livestats_until(link, windows_dir, LOL_SIGNAL_END_SECOND)` — see §3.6. Drop → audit reason, skip signals/market for that card.
2. Tokens via `parse_token_pair`. Prior via `lookup_strict_prior` (same books window as Stage 05: spawn-61s through last grid wall + lag + 300s for the labeled slice; for inference, last grid wall + lag is enough for current mid).
3. **Labeled 0..540:** `join_market_rows` on grid rows with `second <= 540`. Compare to validation (§3.4.5).
4. **Inference 541..899:** same `GridRow` + `lookup_market_p_after(wall, LOL_SOURCE_LAG_SECONDS)` + same prior. **Do not** look up +300s. Missing/non-finite current mid → skip that second (gap). Do not interpolate frames or mids. Stop the integer-second loop at `min(899, floor(last_game_time))`.
5. `state_ts_us` on every signal row = `GridRow.state_wall_us` (selected **frame** wall, same clock Stage 05 used for the market join). That is the exact wall timestamp. Pause-adjusted **second** is `GridRow.second`.
6. Real game end: last `ClockFrame.game_time`. If `floor(last_game_time) < 1200`, game ended early: `still_going_at_1200=False`, `game_ended_at` = last frame wall, market seconds `0..floor(last_game_time)`, signals end there. If `>= 1200`, cutoff applies: `still_going_at_1200=True`, `game_ended_at` / cutoff wall = pause-adjusted wall of second 1200.
7. Market seconds: integer S from 0 through `min(1200, floor(last_game_time))` inclusive when still going, else through last game second. **Theoretical pause-adjusted second boundary** for `state_ts_us` (spawn + S + pauses whose game_time start is before S) — this is the 1 Hz mid clock, distinct from signal frame wall. At that wall: `find_asof_quote` + `resolve_market_pair` (**no** +25s lag). Preserve `stale_quote` / `missing_quote` / `inconsistent_pair`; never copy the previous second's mid.
8. Cutoff gate: if still going and second-1200 status is not `ok`, `eligible=False`, reason `missing_cutoff_midpoint`. Do not write a stale last mid into that cell to pass the gate.
9. Replay window: `replay_start = spawn_wall - 2h`, `replay_end = game_ended_at + 1min` (game_ended_at already cutoff-capped). Required channels over that window (§1.4). Fail → `missing_required_channel`.
10. Eligible iff: livestats ok, required channels present, at least one signal row, and cutoff mid ok when still going.

Book load window for market seconds: first second wall − `MAX_BOOK_AGE_SECONDS` through last second wall + `MARKOUT_TAIL_SECONDS` (600s) so 300s markout after second 899 still has quotes. `load_token_book` already glob-filters by timestamp.

### 3.6 Grid end parameterization (smallest Stage 05 touch)

`select_grid_rows` currently loops `range(LOL_GRID_START_SECOND, LOL_GRID_END_SECOND + 1)`. Give it a required `end_second: int`. `prepare_map_livestats` keeps its two-arg signature:

```python
def prepare_map_livestats(link, windows_dir):
    """Stage 05 0..540 grid."""
    return prepare_map_livestats_until(link, windows_dir, LOL_GRID_END_SECOND)
```

`prepare_map_livestats_until` is the shared body (read, spawn, pause, invariants, `select_grid_rows(..., end_second)`). Stage 07 calls it with `LOL_SIGNAL_END_SECOND`. Stage 05 tests that call `prepare_map_livestats(link, windows)` stay valid.

`LivestatsOk` does not need to grow TimedFrames. Last game_time = last grid row's selected frame, **except** when the game continues past 899: then `floor(last TimedFrame.game_time)` is required for the 1200 cutoff. So `prepare_map_livestats_until` must return last game_time / last frame wall even if the grid stops at 899.

Add to `LivestatsOk` (or a tiny frozen sidecar the until-function returns): `last_game_time: float`, `last_frame_wall_seconds: float`, and enough pause-clock data to compute `wall_us_for_second(S)` for S in `0..1200`. Implement `wall_us_for_second` next to `assign_game_times` using the same gap>5s rule (do not invent a second pause model). Needed for market-second timestamps and cutoff wall.

Do not run invariants only on 0..540. Stage 05 already validates **all** post-spawn frames; keep that. Validation maps that exist already passed late-frame invariants.

### 3.7 Two clocks (do not mix them)

| Clock | Used for | Source |
|---|---|---|
| Pause-adjusted **second** | `second` feature, grid, 899/1200 bounds | `assign_game_times` / `select_grid_rows` |
| **Frame wall** `state_ts_us` on signals | strategy as-of; market join lag anchor | `GridRow.state_wall_us` |
| **Second-boundary wall** `state_ts_us` on market_seconds | 1 Hz mids, cutoff at 1200, markout series | `wall_us_for_second` |

Mixing these is the likely off-by-pause bug. Tests in §4 lock both.
