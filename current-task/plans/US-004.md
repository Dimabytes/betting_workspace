Accounting is one postprocess pass + one wallet timestamp branch. Do not infer forced-hold from duration ≥ 1200 — that would freeze long Dota maps.

## 3. Behavior contract

### 3.1 Engine / strategy hook

**No `poly-maker` edit. No new `DotaMakerConfig` field.**

Hook is the existing `game_end_ns` already passed from `context.game_ended_at`:

1. LoL still-going: Stage 07 capped wall → freeze at second 1200, cancel live quote with `cancel_latency_ns`, no new BUY/SELL.
2. LoL early / all Dota: freeze at real game end, same as today.
3. Books/executions: `BookReplay.end_time = replay_end` (cutoff or real end, plus 1 min). Nothing after that window. Clock continues via `clock_end` + batch `ReplayEndBoundary` so engine settlement at Gamma `closed_at` still runs.
4. Racing fills during cancel wait count (existing `on_order_filled`). Forced-hold inventory is the fill-tape leftover **after** those fills, marked at the **cutoff** mid.

Do not pass `radiant_win` into the strategy config. Do not teach `_evaluate` a second 1200 constant. Do not freeze Dota maps at 1200.

Cancel reason stays `"game_end"`. A distinct `"hard_cutoff"` string is YAGNI when the timestamp is already the 1200 wall for still-going LoL.

### 3.2 `MarketContext` fields

All required (house rule: no optional args). Dota always:

```python
forced_hold=False
cutoff_ns=0  # unused when forced_hold is False
```

LoL `load_lol_replay_lookups` after `build_lol_market_context`:

- `forced_hold = bool(audit_row["still_going_at_1200"])`.
- If `forced_hold`: `cutoff_ns = int(state_ts_us) * NS_PER_US` from the market-seconds row with `second == 1200` (pause-adjusted wall, microsecond precision). Do **not** use `datetime_to_ns(game_ended_at)` — audit ts is `round(unix seconds)` and will miss exact mid match. Missing 1200 row on an eligible still-going card → `ValueError` (Stage 07 contract bug).
- If not `forced_hold`: `cutoff_ns=0`.

`clock_end` formula unchanged: `max(game_ended_at, market_closed_at) + 1min`. For still-going LoL that still reaches Gamma close.

### 3.3 Postprocess formulas

New helper in `postprocess.py` (or `marks.py` for the mid lookup only):

```text
qty[t]     = sum BUY qty on token t − sum SELL qty on token t   # all fills for that (match, arm)
cash       = result.cash_flow                                   # cash_before_rebate
p          = lookup_exact_mid(series, context.cutoff_ns)        # None if ts missing
mid[t]     = token_mid(p, t, radiant_token_index)               # only if p is not None
settle[t]  = settlement_value_for_token(t, radiant_token_index, radiant_win)

pnl_at_cutoff = cash + qty[0]*mid[0] + qty[1]*mid[1]
tail_pnl      = qty[0]*(settle[0]-mid[0]) + qty[1]*(settle[1]-mid[1])
settled_pnl   = pnl_at_cutoff + tail_pnl
              = cash + qty[0]*settle[0] + qty[1]*settle[1]
```

`radiant_win` / `settle[t]` are applied **here**, after replay. Winning token 1.0, losing 0.0.

**Forced-hold + exact mid present:** write qty, both mids, the three PnLs.

**Forced-hold + exact mid missing:** do **not** call `lookup_reference_mid`. Store `cutoff_mid_0/1=None`, still store qty from fills, set `pnl_at_cutoff=0`, `tail_pnl=0`, `settled_pnl=0`, and **exclude** that row from arm PnL sums (shares may still count). Eligible production cards should not hit this; the test is the fail-closed guard.

**Not forced-hold (Dota, LoL early end, flattened or not):**

```text
forced_hold=False
cutoff_qty_0=0, cutoff_qty_1=0
cutoff_mid_0=None, cutoff_mid_1=None
pnl_at_cutoff=engine_pnl
tail_pnl=0
settled_pnl=engine_pnl
```

Ordinary leftover at real game end stays in `engine_pnl` / `terminal_*`. It is not a 1200 tail.

Call attach once per batch before `write_results_checkpoint`. Merge/resume rows that already have columns are left as stored.

### 3.5 Wallet settlement timestamp

In `_build_tape_events`, for each non-terminated result that has fills:

```text
if contexts[match_id].forced_hold:
    ts = max(context.cutoff_ns, datetime_to_ns(context.market_closed_at))
else:
    ts = datetime_to_ns(parse_utc(result.game_ended_at))  # today
```

No extra minute on the settle event (today has none).

Dota `forced_hold=False` → identical tape. A still-going LoL map with `closed_at` hours after cutoff keeps the lot open until `closed_at`, so `span_seconds` / `maps_at_once` reflect occupied capital until known resolution.
